## 一、教育与人的发展

### 1. 个体身心发展概念

- 个体的身心发展指个体随年龄增长而发生的身心有规律的、连续变化的过程
- 包括：**生理发展**（成熟标志=生殖能力）+ **心理发展**（认知发展+社会性发展，成熟标志=自我意识）
- 人的身心发展的特殊性：①在社会实践过程中实现 ②具有**能动性**

### 2. ★五大身心发展规律

| 规律 | 具体表现 | 教学启示 | 古语/例子 |
|---|---|---|---|
| **顺序性** | 低级→高级、简单→复杂、量变→质变；不可逆、不可逾越 | **循序渐进** | "陵节而施""学不躐等""欲速则不达""盈科后进""拔苗助长" |
| **阶段性** | 不同年龄阶段不同特征、不同主要矛盾、不同发展任务 | **不能搞"一刀切"**；注意阶段衔接过渡 | 小学教育中学化；少年期="危险期/心理断乳期"；八个阶段（乳儿→婴儿→幼儿→童年→少年→青年→成年→老年） |
| **不平衡性** | ①同一方面不同年龄速度不同 ②不同方面发展不同时 | 抓**关键期**（最佳期/敏感期） | 身高体重两个高峰期；2~3岁语言关键期；印度狼孩 |
| **互补性** | 生理↔生理（盲人耳聪）；生理↔心理（身残志坚） | **长善救失**、扬长避短 | 盲人听觉敏锐；失去视觉后触觉更灵敏 |
| **个别差异性** | 群体差异（男/女）、个体差异（身心的所有方面） | **因材施教** | "聪明早慧"vs"大器晚成" |

#### 附加：稳定可变性 & 整体性

| 规律 | 要点 |
|---|---|
| **稳定性和可变性** | 稳定性：同一年龄段身心发展顺序/过程/速度大体相同；可变性：不同环境和教育下发展水平有差异 |
| **整体性** | 教师面对的是活生生的整体的人；教学要促进学生的整体发展 |

#### 高频考点速查

| 古语 | 对应规律 |
|---|---|
| "陵节而施""学不躐等" | **顺序性**→循序渐进 |
| "一刀切""小学教育中学化" | **阶段性**（违反了阶段性） |
| 关键期/敏感期/最佳期 | **不平衡性** |
| "身残志坚""盲人耳聪" | **互补性** |
| "聪明早慧""大器晚成""一把钥匙开一把锁" | **个别差异性**→因材施教 |
| 量变到质变（连带"质的飞跃"）| **阶段性**（注意！不是顺序性） |
| 由低到高、由简到繁的连续过程 | **顺序性** |
| "当其可之谓时，时过而后学，则勤苦而难成" | **不平衡性**（关键期） |

### 3. ★身心发展的动因

#### （1）内发论（自然成熟论/预成论/生物遗传决定论）

| 代表人物 | 核心观点 |
|---|---|
| **孟子** | "仁义礼智非由外铄我也，我固有之也"（性善论） |
| **弗洛伊德** | 性本能 |
| **威尔逊** | 基因复制 |
| **格赛尔** | **成熟机制**（双生子爬梯实验，"成熟势力说"） |
| **霍尔** | "**一两的遗传胜过一吨的教育**"（复演说） |
| **高尔顿** | 优生学；血统论 |
| 卢梭 | "出自造物主之手的东西都是好的" |
| 柏拉图 | 观念先天存在 |
| 桑代克 | 双生子智商研究：智慧80%决定于基因 |
| 中国性善性恶论、基督教原罪说、董仲舒/韩愈性三品 | 属于内发论 |

#### （2）外铄论（环境决定论/外塑论/经验论）

| 代表人物 | 核心观点 |
|---|---|
| **荀子** | "人之性恶，其善者伪也"（性恶论） |
| **洛克** | **"白板说"** |
| **华生** | "给我一打健康的婴儿……"（**首选环境决定论**） |
| 墨子 | 人性素丝说 |
| 奈特·邓拉普 | 《有本能吗？》（强调没有本能） |

#### （3）二因素论（辐合论）和多因素相互作用论

| 理论 | 代表人物 | 观点 |
|---|---|---|
| 二因素论 | **斯特恩**（施泰伦） | 遗传**+**环境（相加说） |
| 二因素论 | **吴伟士**（伍德沃斯） | 遗传**×**环境（相乘说） |
| 多因素相互作用论 | **皮亚杰**、马克思主义 | 内外因在实践中相互作用 |

> ⚠️ **拔高题**："把教育隐喻为'园艺'、学生比作'花朵'、教师为园丁"→倾向于**环境决定论**（外铄论）；"把教育隐喻为'塑造'"→倾向于**外铄论**。

### 4. ★影响身心发展的四大因素

| 因素 | 地位/作用 | 关键要点 |
|---|---|---|
| **遗传** | 必要**物质前提**；提供**可能性**；不能决定发展 | 成熟程度制约发展过程（三翻六坐八爬）；差异性有一定影响；具有**可塑性**；随发展作用减弱 |
| **环境** | 外部客观条件；使可能性变为**现实性**；**更根本**（相对于遗传） | 双重性（积极/消极）；零星无计划；人具有主观能动性 |
| **学校教育** | **主导作用** | 主导原因：三有（目的/计划/组织）+教师+全面控制+全面系统深刻；表现：社会规范+加速发展+即时延时+开发个性+唤醒生命自觉；条件：教育自身状况是**基础和前提** |
| **个体主观能动性** | **决定性因素** | 遗传→可能性；环境→现实性；学校教育→主导；主观能动性→**决定** |

#### 教育的促进作用（表现）

| 层面 | 要点 |
|---|---|
| 加速人的发展 | 孟子的"性善论"→教育可以加速善性的扩充 |
| 发掘人的潜力 | 三大要素：高度的自信、坚定的意志、强烈的愿望 |
| 提升人的价值 | 教育教会人们驾驭知识技能、怀疑知识技能 |
| 健全人的个性 | 发挥人的力量、唤醒生命自觉意识 |

#### 教育万能论

代表人物：德国**康德**、美国**华生**、法国**爱尔维修**。
- 爱尔维修："只有环境和教育，才能把牛顿变成科学家"
- 康德："人只有通过教育才能成为一个人。人是教育的产物"
- 洛克（倾向万能论）："十分之九都是教育所决定的"

## 二、教育与社会的发展

### 1. 教育与生产力 ⭐高频

| 方向 | 要点 |
|---|---|
| **生产力对教育的制约** | ①决定教育发展的**规模和速度** ②制约人才**培养规格**和教育**结构** ③制约教育**内容/方法/手段/组织形式** |
| **教育对生产力的促进**（经济功能） | ①**再生产劳动力** ②**再生产科学技术**（科学知识再生产最主要途径=**学校教育**） ③人力资本理论：教育投资是人力资本的**核心** |

### 2. 教育与政治经济制度 ⭐高频

| 方向 | 要点 |
|---|---|
| **政治对教育的制约** | ①决定教育**性质/领导权/受教育权** ②决定教育**目的** ③决定教育**内容**（特别是政治思想方面） ④决定教育**体制** |
| **教育对政治的促进**（政治功能） | ①培养所需人才 ②促进政治**民主化** ③传播思想、形成舆论 ④促进年轻一代**政治社会化** |

### 3. 教育与文化 ⭐高频

| 方向 | 要点 |
|---|---|
| **文化对教育的制约** | ①影响教育**目的**的确立 ②影响教育**内容**的选择 ③影响教育教学**方法**的使用 ④影响教育的**价值取向** |
| **教育对文化的促进**（文化功能） | ①**传递和保存**文化（最基本功能） ②**选择和提升**文化 ③**传播和交流**文化 ④**更新和创造**文化 |

> 📌 教育的社会功能中最深远的功能=**文化功能**（与人类社会共始终）

### 4. 教育与科学技术 & 人口

| 方向 | 要点 |
|---|---|
| **科技对教育** | 改变教育者的观念；影响教育数量和质量；影响教育内容/方法/技术 |
| **教育对科技** | 完成科学知识再生产；推进科学体制化；具有科学研究功能 |
| **人口对教育** | 人口数量/质量/结构影响教育 |
| **教育对人口** | 教育是控制人口增长的重要手段；提高人口质量；优化人口结构 |

### 5. 教育与社会关系的主要理论 ⭐高频

| 理论 | 代表人物 | 核心观点 |
|---|---|---|
| **人力资本理论** | **舒尔茨**、贝克尔 | 人力资本是经济增长的关键；**教育投资是人力资本的核心**；人口质量重于人口数量 |
| **筛选假设理论** | 阿罗、斯宾塞（伯格） | 教育的作用是**筛选/信号/标识**；文凭是能力的信号 |
| **劳动力市场理论** | 皮奥利、多林格 | 劳动力市场分为**主要市场**（高工资/好条件）和**次要市场**（低工资/差条件）；教育只是决定进入哪个市场 |

## 四、高频考点速查

### 最爱考的对应关系

| 题目描述 | 答案 |
|---|---|
| 教育活动的基本规律 | ①教育与**人的身心发展** ②教育与**社会发展** |
| 双生子爬梯实验 | 格赛尔→内发论→**成熟机制** |
| "一两的遗传胜过一吨的教育" | **霍尔**→内发论 |
| "白板说" | 洛克→**外铄论** |
| 教育发挥主导作用的基础和前提 | **教育的自身状况** |
| 教育在人身心发展中起什么作用 | **主导作用** |
| 最终决定人的发展的是 | **个体主观能动性** |
| "关键期"概念对应 | **不平衡性** |
| 生产力决定教育的 | **规模和速度** |
| 人力资本理论核心 | 教育投资 |
| 教育的最基本文化功能 | **传递和保存文化** |

### 高频判断题陷阱

1. ❌"遗传决定人的发展"→遗传只是提供了可能性，不能决定
2. ❌"环境决定人的发展"→环境提供现实条件，人具有主观能动性
3. ❌"学校教育能决定人的发展"→学校教育起主导作用，但教育是有条件的
4. ❌"人的发展既体现出量的积累，又表现出质的飞跃→顺序性"→这是**阶段性**
5. ❌"个体身心发展是由量变到质变的连续不断的过程→阶段性"→这是**顺序性**（由低到高由简到繁）
6. ❌"洛克的'白板说'属于内发论"→属于**外铄论**
7. ❌"格赛尔的双生子实验支持外铄论"→支持**内发论**（成熟机制）
