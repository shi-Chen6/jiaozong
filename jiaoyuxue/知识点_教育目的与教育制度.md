## 一、教育目的

### 1. 概念与特征 ⭐高频

- **含义**：对受教育者提出的总要求，规定把受教育者培养成什么样的人，是培养人的**质量规格标准**
- **地位**：教育的**核心问题**（首要问题=培养什么样的人）；教育的**出发点和归宿**、主题和灵魂、最高理想；是社会需求的集中反映，是教育性质的集中体现
- **构成**（两个部分）：①人的**身心素质**的培养规格和质量（**核心部分**）②所要培养的人的**社会价值**（发展方向）
- **广义**：人们对受教育者的期望（国家/社会机构/家长/教师等）
- **狭义**：各级各类学校对人才培养的要求

#### 特征

- 版本一：**宏观性**、**预期性**（理想性）、**强制性**、**时代性**、客观与主观的统一
- 版本二：强制性、宏观性、理想性、历史性、阶级性

### 2. 教育目的与教育方针的区别 ⭐高频

| 维度               | 教育目的                                   | 教育方针                                           |
| ------------------ | ------------------------------------------ | -------------------------------------------------- |
| **核心内容** | 培养什么样的人                             | 培养什么样的人 + 怎样培养人                        |
| **性质**     | 理论术语、学术性概念（较**理想**）   | 工作术语、**政治性**概念（较**现实**） |
| **隶属**     | 教育基本理论范畴                           | 教育政策学范畴                                     |
| **约束力**   | 团体或个人提出，有时可**不具约束力** | 政府/政党提出，具有**强制性**                |
| **侧重**     | 人才培养**规格**做规定               | 教育事业**发展方向**提要求                   |
| **影响力**   | ——                                       | 对教育工作影响**大于**教育目的               |

#### 教育方针

- 国家教育工作的基本政策和指导思想，是教育政策的**最高表现形式**
- 构成：①教育性质与方向（为社会主义现代化建设服务）②培养人的质量规格（德智体美劳全面发展）③培养人的根本途径和原则（与生产劳动和社会实践相结合）
- **教育目的是教育方针的核心内容**；教育方针包含教育目的
- 可以近似看作教育目的的政策性表达

#### 教育目的与教育目标

- 教育目的**大于**教育目标，教育目标大于培养目标（有时也可等同于培养目标）
- 教育目的具有**终极性**，教育目标是具体努力方向

### 3. ★教育目的的层次结构 ⭐高频

| 层次（从高到低）                                | 内容                            | 制定主体          |
| ----------------------------------------------- | ------------------------------- | ----------------- |
| **国家的教育目的**                        | 国家对培养人的总要求            | 国家              |
| **各级各类学校的培养目标**                | 不同层次/类型学校的具体培养要求 | 学校/教育行政部门 |
| **课程目标**（课程教学目标/学科教学目标） | 某门课程要达到的目标            | 课程专家/教师     |
| **教师的教学目标**                        | 具体教学活动要达到的目标        | 教师              |

### 4. ★教育目的的功能 ⭐高频

| 功能                             | 要点                   |
| -------------------------------- | ---------------------- |
| **导向作用**（定向作用）   | 为教育指明方向         |
| **调控作用**（调节、控制） | 对教育活动进行调控     |
| **激励作用**               | 激励教育者和受教育者   |
| **评价作用**               | 作为衡量教育质量的标准 |
| **选择作用**               | 选择教育内容、方法等   |

### 5. 选择与确立的基本依据

- 社会依据：社会生产力发展水平、政治经济制度、文化传统等
- 人的依据：人的身心发展规律和需要
- 理论依据：马克思主义关于人的全面发展学说

### 6. ★有关教育目的的理论 ⭐高频

| 理论                                   | 代表人物                                                   | 核心观点                                                                         |
| -------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **宗教本位论**（神学教育目的论） | 奥古斯丁、托马斯·阿奎那                                   | 教育为神服务；培养虔诚的教徒                                                     |
| **社会本位论**                   | **纳托普、凯兴斯泰纳、涂尔干、孔德**                 | 教育目的应从社会需要出发；培养**合格公民**；**社会价值高于个人价值** |
| **个人本位论**                   | **卢梭、裴斯泰洛齐、福禄贝尔、孟子**                 | 教育目的应从个人需要出发；培养**自然人**；**个人价值高于社会价值**   |
| **教育无目的论**                 | **杜威**                                             | 教育的过程在它自身以外没有目的；**教育即生长**                             |
| **生活本位论**                   | **斯宾塞**（教育预备生活说）·杜威（教育适应生活说） | 教育为未来完满生活做准备/教育即生活                                              |
| 文化本位论                             | 狄尔泰、斯普朗格                                           | 以文化为中介促进个体的发展                                                       |

#### 社会本位论 vs 个人本位论 对比

|                    | 社会本位论                                 | 个人本位论                             |
| ------------------ | ------------------------------------------ | -------------------------------------- |
| **出发点**   | 社会需要                                   | 个人需要                               |
| **培养目标** | 合格公民                                   | 自然人                                 |
| **价值取向** | 社会价值高于个人价值                       | 个人价值高于社会价值                   |
| **代表人物** | 纳托普、凯兴斯泰纳、涂尔干、孔德           | 卢梭、裴斯泰洛齐、福禄贝尔、孟子       |
| **名言**     | "教育在于使年轻一代系统地社会化"（涂尔干） | "出自造物主之手的东西都是好的"（卢梭） |

### 7. 我国的教育目的

- **我国的教育目的**（1999年）：实施素质教育，以培养学生**创新精神和实践能力**为重点，造就有理想、有道德、有文化、有纪律的德智体美等全面发展的社会主义建设者和接班人
- **我国的教育方针**（2021年《教育法》）：教育必须为社会主义现代化建设服务、为人民服务，必须与**生产劳动和社会实践相结合**，培养**德智体美劳全面发展的社会主义建设者和接班人**
- **立德树人**是教育的根本任务

### 8. 全面发展教育（五育）

| 各育                   | 地位                             | 任务         |
| ---------------------- | -------------------------------- | ------------ |
| **德育**         | 灵魂、统帅、**方向和动力** | 培养道德品质 |
| **智育**         | 前提、**认识基础**         | 传授知识技能 |
| **体育**         | 物质基础                         | 增强体质     |
| **美育**         | 动力、协调作用                   | 培养审美能力 |
| **劳动技术教育** | 综合体现                         | 传授劳动技术 |

五育各有特点但相辅相成，德育是**方向保证**，智育是**认识基础**，体育是**物质基础**。

## 二、教育制度

### 1. 概念与特征

- **教育制度**：一个国家各级各类教育机构与组织体系及其管理规则的总和
- 广义：国民教育制度（包括学校和非学校教育机构）
- 狭义：**学校教育制度**（简称**学制**）

### 2. ★学校教育制度（学制）⭐高频

#### 概念与地位

- 学制是一个国家各级各类学校的**总体系**，规定各级各类学校的性质、任务、入学条件、修业年限及其相互关系
- **地位**：教育制度的核心和主体；**国民教育制度的核心**

#### 学制的类型

| 类型                               | 代表国家                 | 特点                                                                           |
| ---------------------------------- | ------------------------ | ------------------------------------------------------------------------------ |
| **双轨制**                   | 英国、法国、德国（西欧） | 一轨学术教育（贵族）→大学；一轨职业教育（平民）→就业；两轨**互不贯通** |
| **单轨制**                   | 美国                     | 所有学生进入统一的学校系统；体现**教育民主化**                           |
| **分支型学制**（中间型/Y型） | 苏联、中国               | 基础教育阶段统一，高中后分流为普通教育和职业教育                               |

#### 我国现行学制

- **从单轨制发展而来，兼具分支型特征**
- 学校教育系统：学前教育→初等教育（小学）→中等教育（初中+高中）→高等教育
- **义务教育**：9年（小学6年+初中3年）

### 3. 义务教育制度

- 定义：国家统一实施的所有适龄儿童、少年必须接受的**强制性、免费性、普及性**的教育
- 我国：1986年《义务教育法》确立，目前为**九年义务教育**

### 4. 终身教育制度（参考CH1内容）

- 贯穿一生、包括所有教育形态；1965年保罗·朗格朗提出；当代最具影响力的两大思潮之一

### 高频判断题陷阱

1. ❌"教育方针=教育目的"→教育方针包含教育目的，教育目的是其核心
2. ❌"教育目的对教育实践具有强制性"→教育方针有强制性，教育目的有时可不具约束力
3. ❌"杜威是社会本位论"→杜威是**教育无目的论**（也属生活本位论）
4. ❌"学制就是教育制度"→学制是教育制度的**核心和主体**（狭义教育制度）
5. ❌"卢梭是社会本位论"→卢梭是**个人本位论**（强调自然人）
