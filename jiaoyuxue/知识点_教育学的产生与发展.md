## 一、教育学概述

### 1. 概念与源流 ⭐高频

- **教育学概念**：教育学是研究教育现象和教育问题，**揭示教育规律**的一门科学
- **源与流**：教育学发展中的"源"指**教育实践**，"流"指**教育理论**
- **研究对象**：**教育现象**（教育的外部表现形式，包括社会现象和认识现象）+ **教育问题**（内在动力）
- **研究任务**：解释教育问题和现象；**揭示教育规律**（根本任务）；指导教育实践；探讨教育价值与教育艺术
- **发展历程**：版本一（萌芽→创立→发展）；版本二（萌芽→独立形态→多元化→现代化）

### 2. 教育学的分支

| 分支 | 研究对象 |
|---|---|
| **普通教育学** | 中小学教育（师范学校公共教育学课程） |
| 学前教育学 | 幼儿教育 |
| 高等教育学 | 高等教育现象及规律 |
| 元教育学 | 以教育理论自身为研究对象的学科 |

### 3. 各阶段特点

| 阶段 | 特点 |
|---|---|
| **萌芽时期** | ①教育学尚未从哲学/伦理学/政治学中独立出来 ②著作多为论文形式，经验描述或猜测 ③以类比、比喻、格言、寓言为主；教育问题的提出是标志 |
| **创立时期** | ①教育问题成为专门研究领域 ②形成专门概念体系 ③有科学方法 ④出现系统教育学著作 ⑤产生专门研究机构 |
| **发展时期** | 多元教育学流派并存（实验/文化/实用主义/马克思主义/批判等） |

## 二、萌芽时期（中外教育思想）

### 1. 孔子 ⭐高频（11题）

| 维度 | 要点 |
|---|---|
| **人性论** | "性相近，习相远"（**外铄论**，强调环境与教育）；"唯上智与下愚不移"（性三品，内发论） |
| **教育对象** | **"有教无类"**（教育起点机会均等；针对奴隶主贵族的"有教有类"提出）；"自行束脩以上，吾未尝无诲焉" |
| **教育功能** | 社会作用：**庶、富、教**（最早论述教育与经济发展关系的教育家）；个人作用："性相近，习相远" |
| **教育目的** | 培养德才兼备的君子（"学而优则仕"——子夏） |
| **教育内容** | **六艺**（礼乐射御书数）+ **六经**（诗书礼乐易春秋）；偏重人事文事道德，**轻视科技生产知识** |
| **教学方法** | 学思行并重（"学而不思则罔"）；启发诱导（"不愤不启，不悱不发"，最早提出启发式教学）；因材施教（"闻斯行诸"）；温故知新 |
| **教师观** | 学而不厌、诲人不倦、温故知新、以身作则、关爱学生、**教学相长**（孔子教师观包含教学相长，但教学相长原文出自《学记》） |

**孔子名言对应：**
- "不愤不启，不悱不发"→**启发性原则**
- "视其所以，观其所由，察其所安"→**因材施教**
- "自行束脩以上，吾未尝无诲焉"→**有教无类**
- "性相近，习相远"→**环境决定论**
- "吾十有五而志于学……七十而从心所欲"→**终身教育**思想
- "其身正，不令而行"→**榜样示范法**
- "知之者不如好之者，好之者不如乐之者"→关注兴趣
- "无欲速……欲速则不达"→**循序渐进**

> ⚠️ **易错陷阱**："教学相长"原文出自《学记》，但它是孔子教师观的内容。题干问"以下出自《论语》的"时**不选**教学相长；问"以下属于孔子教师观"时**可选**教学相长。

### 2. 孟子 ⭐高频（3题）

| 维度 | 要点 |
|---|---|
| **人性论** | **性善论**（内发论）；"仁义礼智，非由外铄我也，我固有之也" |
| **教育目的** | **"明人伦"**（父子有亲、君臣有义、夫妇有别、长幼有序、朋友有信） |
| **理想人格** | **大丈夫**："富贵不能淫，贫贱不能移，威武不能屈" |
| **修养方式** | **持志养气、动心忍性、存心养性、反求诸己** |
| **教育方法** | 深造自得（"君子深造之以道，欲其自得之也"）、盈科后进（"流水之为物也，不盈科不行"）、教亦多术（因材施教）、专心致志、启发诱导（"君子引而不发，跃如也"） |
| **名言** | "穷则独善其身，达则兼济天下"；"天将降大任于斯人也"（实际锻炼法）；"得天下英才而教育之"（最早教-育连用） |

### 3. 荀子 ⭐（1题）

| 维度 | 要点 |
|---|---|
| **人性论** | **性恶论**（**外铄论**）；教育作用：**"化性起伪"** |
| **地位** | "最为老师，三为祭酒"；**最早将"道"和"德"连用** |
| **教育目的** | 培养**大儒**（人才层次：俗人→俗儒→雅儒→**大儒**） |
| **学习过程** | **闻见知行**："不闻不若闻之，闻之不若见之，见之不若知之，知之不若行之。学至于行之而止矣" |
| **教育内容** | 五经，**《礼》是荀子教育思想的核心和重点** |
| **教师观** | 先秦儒家中最提倡尊师；"师术有四"：尊严而惮、耆艾而信、诵说而不陵不犯、知微而论 |
| **名言** | "青，取之于蓝而青于蓝"（教学相长）；"蓬生麻中不扶而直"（环境的作用）；"不积跬步无以至千里"（循序渐进） |

### 4. 墨子 ⭐（4题）

| 维度 | 要点 |
|---|---|
| **思想基础** | 兼爱、非攻 |
| **人性论** | **人性素丝说**："染于苍则苍，染于黄则黄"（**外铄论**，环境的作用） |
| **教育目的** | 培养**兼士/贤士** |
| **知识来源** | 亲知（直接经验，最重要）、闻知（间接经验）、说知（推理，**最高途径**） |
| **教学原则** | 主动施教（"虽不叩必鸣"的强说人精神）、创造（述而又作）、实践（士虽有学，而行为本）、量力（"深其深，浅其浅，益其益，尊其尊"—先选量力，无量力选因材施教） |
| **教育内容** | ①道德教育（兼爱非攻等） ②科学和技术教育（**最大特色**：光学小孔成像、数学圆的定义"一中同长"、力学定义） ③"**三表法**"培养思维能力 |
| **儒墨对比** | 同：都重道德和文史教育；异：墨重科技/儒家轻视科技；墨反对重礼厚葬（节葬）、反对乐教（非乐）；儒家"不叩不鸣""述而不作" vs 墨家"虽不叩必鸣""述而又作" |

### 5. 道家与法家

| 学派 | 要点 |
|---|---|
| **道家**（老子、庄子） | 一切任其自然，人性论"自然人性论"；老子：文化堕落论/人性复归论/"绝圣弃智"；庄子："道法自然" |
| **法家**（商鞅、韩非） | 禁诗书、"**以法为教**"；禁私学、"**以吏为师**" |

### 6. 经典著作

#### 《大学》
- 相传孔子弟子**曾子**所作
- **三纲领**："大学之道，在明明德，在亲民，在**止于至善**"（终极目标：止于至善）
- **八条目**：格物→致知→诚意→正心→修身→齐家→治国→平天下

#### 《中庸》
- 孔子之孙**子思**所作
- "天命之谓性，率性之谓道，修道之谓教"
- 学习过程五阶段：**博学之，审问之，慎思之，明辨之，笃行之**（学→问→思→辨→行）
- "凡事豫则立，不豫则废"→备课的重要性

#### 《学记》⭐⭐⭐（世界第一的教育学著作）

> 中国古代最早、**世界上最早**的一篇专门论述教育和教学问题的论著。战国晚期思孟学派作品，据郭沫若考证作者为**乐正克**。被称为"**教育学的雏形**"。

| 原文 | 蕴含思想 |
|---|---|
| "君子如欲化民成俗，其必由学乎" | 教育与**政治**的关系 |
| "玉不琢，不成器；人不学，不知道" | 教育的**个体功能** |
| "建国君民，教学为先" | 教育的**政治功能** |
| "学然后知不足，教然后知困……教学相长也" | **教学相长**（世界首次提出此命题） |
| "道而弗牵，强而弗抑，开而弗达" | **启发性原则** |
| "学者有四失……长善而救其失者也" | **长善救失**（首选长善救失，无则选因材施教） |
| 预（禁于未发）、时（当其可）、孙（不陵节而施）、摩（相观而善） | "**预时孙摩**"四原则 |
| "幼者听而弗问，学不躐等也" | **循序渐进** |
| "时教必有正业，退息必有居学"、"藏焉修焉，息焉游焉" | **课内外相结合**（臧息相辅） |
| "语之而不知，虽舍之可也" | **量力性**（可接受性）原则 |
| "善学者，师逸而功倍" | **教会学生学习** |
| "当其为师，则弗臣也" | **尊师重道** |
| "独学而无友，则孤陋而寡闻" | **讨论法**/互相观摩 |
| "学无当于五官，五官不得不治" | **复述策略** |
| "比年入学，中年考校……谓之小成/大成" | 西周的大学**考核制度** |

> **各种首选速记**：①"深其深，浅其浅"→首选量力性，次选因材施教 ②"学者有四失"→首选长善救失，次选因材施教 ③"及其数进而不顾其安"→首选循序渐进，次选量力性 ④"今之教者，呻其占毕……教人不尽其材"→首选因材施教，次选循序渐进/量力性

### 7. 其他中国教育家

| 人物 | 要点 |
|---|---|
| **董仲舒** | 三大文教政策：罢黜百家独尊儒术、兴太学、重视选举；道德核心：三纲五常；性三品说；"汉代孔子" |
| **王充**（东汉） | 著作《论衡》；人才层次：文吏→儒生→通人→文人→**鸿儒**（兴论立说，首倡培养创造性人才）；学习方法：学知与闻见、思考与求是、"问难"与"距师"（民主平等师生关系） |
| **颜之推** | 著作《颜氏家训》（最早的家庭教科书）；教育目的：治国人才/士大夫；儿童教育：及早施教、严慈相济 |
| **韩愈** | 著作《师说》；性情三品说；教师作用：**传道授业解惑**；"业精于勤荒于嬉" |
| **王夫之** | 人性说：性日生日成，后天习得；教育作用：继善成性 |
| **朱熹** | **朱子读书法**（六法）：循序渐进、熟读精思（无疑→有疑→解疑）、虚心涵泳、切己体察、着紧用力、**居敬持志**（读书关键）；"孔子施教，各因其材"；教育阶段：小学教事（8-15岁）→大学教理（15岁后）；"宽著期限，紧着课程" |
| **王阳明**（王守仁） | 心即理、致良知（孟子+大学）、求本心（独立思考）；**"随人分限所及"**（量力性/可接受性）；重视儿童教育："大抵童子之情，乐嬉游而惮拘谨" |

### 8. 外国萌芽时期教育思想

#### 苏格拉底 ⭐
- "西方的孔子"（述而不著）；西方最早采用启发式教学；古希腊最早提出发现法
- 德育："**美德即知识**""智慧即德行"
- **苏格拉底法（产婆术/问答法/启发法）**：讥讽→**助产术**→归纳→**定义**（最后一步）；遵循从具体到抽象、从已知到未知、从个别到一般
- 名言："教育不是灌输，而是点燃火焰"

#### 柏拉图 ⭐
- 著作《**理想国**》（西方三大里程碑之一，另两本是卢梭《爱弥儿》、杜威《民主主义与教育》）
- 学习即回忆（内发论）；理念世界与现实世界
- 理想国三类人：哲学王（金/智慧）、军人（银/勇敢）、劳动者（铜/节制）
- **最早提倡"寓学习于游戏"**；提出四艺（算术几何天文音乐）→与三艺合称七艺
- 西方教育史上**第一个提出完整学前教育思想**并建立完整教育体系的人

#### 亚里士多德 ⭐
- 古希腊百科全书式哲学家；"古代的黑格尔"
- **灵魂论**：植物灵魂（体育）→动物灵魂（德育）→理性灵魂（智育，最高层次）；最早从理论上论证**和谐发展教育**的可能性和必要性；音乐教育是核心
- 首次提出"**教育遵循自然**"原则
- **自由教育**思想（文雅教育）：适合自由民，基本条件是闲暇时间和自由学科

#### 昆体良
- 著作《雄辩术原理》（《论演说家的教育》→**西方最早的教育著作**，也是西方最早的**教学法**论著）
- 主张班级授课制思想的萌芽

| **卢梭** | 《**爱弥儿**》 | **自然主义**教育思想；"**发现儿童**"；"教育要适应儿童天性的发展" |
| **康德** | 《论教育》 | 最早在大学（哥尼斯堡）开设**教育学讲座** |
| **裴斯泰洛齐** | 《林哈德与葛笃德》 | "**教育心理学化**"口号；**要素教育**理论；"人类教育之父" |

| **斯宾塞** | 《教育论》 | "什么知识最有价值？"—**科学知识**；"**教育预备生活说**"（生活本位论）；课程论 |
| **杜威** | 《**民主主义与教育**》 | **实用主义教育学**代表；"教育即生活""教育即生长""教育即经验的改组改造"；**三中心**：儿童中心、活动中心、经验中心；"**从做中学**"；**五步教学法** |

## 四、发展时期 ⭐

### 现代教育学流派

| 流派 | 代表人 | 核心观点 |
|---|---|---|
| **实验教育学** | 梅伊曼、拉伊 | 用**实验**方法研究教育 |
| **文化教育学**（精神科学教育学） | 狄尔泰、斯普朗格 | 教育是**文化**过程 |
| **实用主义教育学** | 杜威、克伯屈 | 教育即生活/生长/经验改造；儿童中心 |
| **马克思主义教育学** | 凯洛夫、杨贤江 | 教育与社会生产劳动相结合 |
| **批判教育学** | 鲍尔斯、金蒂斯、布迪厄 | 教育维护社会不平等 |

### 苏联教育家

### 高频判断题陷阱
1. ❌"《学记》是世界上最早的教育学著作"→应是最早的论著/文献（当时教育学尚未独立）
2. ❌"教育学独立形态的标志是培根提出"→培根只是提出学科名称，独立形态标志是夸美纽斯《大教学论》
3. ❌"赫尔巴特的著作是《大教学论》"→《大教学论》是夸美纽斯；赫尔巴特是《普通教育学》
4. ❌"教学相长出自《论语》"→出自《学记》，但属于孔子教师观
5. ❌"有教无类是真正的教育平等"→是教育**起点**机会均等（非完全平等）
6. ❌"中国最早明确提出'美育'一词的是蔡元培"→首次明确提出"美育"一词的是**王国维**；近代最早提出"美育"教育目标的是蔡元培
