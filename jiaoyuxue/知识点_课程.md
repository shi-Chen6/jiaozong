## 一、课程概述

### 1. 课程概念

- **课程的定义**：课程是学校教育系统的**核心要素**，是社会主导教育价值观的具体表现和集中反映。课程涉及"教师教什么、学生学什么"。
- **课程的地位**：课程是学校教育的**核心**，在教育活动中处于**基础和核心**地位。①课程是教学的主要媒介和学生主要知识源 ②是教师上课和评价教学效果的主要依据 ③是教师从事教育教学的"**施工蓝图**"。

#### 课程一词的由来

| 人物 | 朝代 | 内容 |
|---|---|---|
| **孔颖达** | 唐 | 我国最早提出"**课程**"一词："维护课程，必君子监之"—《五经正义》 |
| **朱熹** | 宋 | 最早提出和**现代"课程"一词现实关联**的人："宽着期限，紧着**课程**""小立课程，大作功夫" |

### 2. 制约课程的因素 ⭐

| 因素 | 要点 |
|---|---|
| **社会因素** | 社会政治、经济、文化发展水平（决定性因素之一） |
| **知识因素** | 科学文化知识的发展水平 |
| **学生因素** | 学生的身心发展规律和特点（**根本性**制约因素） |

## 二、★课程的类型（五大分类）⭐高频

### 分类一：学科课程 vs 活动课程

| | 学科课程 | 活动课程（经验课程） |
|---|---|---|
| **内容组织** | 以学科逻辑体系为核心 | 以儿童的兴趣、需要、经验为核心 |
| **代表人物** | 夸美纽斯、赫尔巴特、斯宾塞 | 杜威、克伯屈 |
| **优点** | 系统性强、逻辑严密 | 激发兴趣、贴近生活、培养实践能力 |
| **缺点** | 脱离生活、忽视学生兴趣 | 系统性和逻辑性不足 |
| **地位** | 最古老、使用范围最广 | 现代教育课程改革中日益受到重视 |

### 分类二：分科课程 vs 综合课程

| 分科课程 | 综合课程 |
|---|---|
| 以学科为单位，各科独立设置 | 打破学科界限，将相关学科内容整合 |
| 例：语文、数学、物理 | 例：科学（物理+化学+生物）、社会（历史+地理） |

### 分类三：必修课程 vs 选修课程

| 必修课程 | 选修课程 |
|---|---|
| 所有学生必须学习的课程 | 学生可以根据兴趣和需要选择 |
| 保证基本的教育质量 | 满足学生的个性发展需求 |

### 分类四：显性课程 vs 隐性课程 ⭐

| | 显性课程（正式课程） | 隐性课程（潜在课程） |
|---|---|---|
| **概念** | 学校情境中以直接的、明显的方式呈现的课程；有计划、有组织的正式课程 | 学校情境中以**间接的、内隐的**方式呈现的课程；非正式、非计划性的 |
| **提出者** | —— | **杰克逊**（《班级生活》） |
| **表现形式** | 课程表中的各门学科 | 校风、班风、师生关系、校园文化、学校制度等 |
| **特点** | 计划性、正式性 | **无意识性、潜移默化** |

> 📌 隐性课程的概念是由美国教育学家**杰克逊**在《班级生活》中首次提出的。

### 分类五：三级课程管理

| 层次 | 内容 | 制定主体 |
|---|---|---|
| **国家课程** | 由国家统一制定，体现国家意志 | 国家 |
| **地方课程** | 由省级教育行政部门制定，反映地方特色 | 省级 |
| **校本课程** | 由学校根据自身情况自主开发 | 学校 |

## 三、课程理论（三大流派）⭐

| 流派 | 代表人物 | 核心观点 |
|---|---|---|
| **学科中心课程论**（知识中心） | 夸美纽斯、赫尔巴特、斯宾塞、**巴格莱**（要素主义） | 以学科知识为中心；强调知识的系统性；**重视学科逻辑** |
| **学生中心课程论**（儿童中心） | **杜威**、克伯屈、**罗杰斯**（人本主义） | 以学生的**兴趣、需要和活动**为中心；**课程即经验** |
| **社会中心课程论**（社会改造主义） | 布拉梅尔德、弗莱雷 | 以社会问题为中心；强调课程为社会改造服务 |

> 📌 **学科中心**=知识本位；**学生中心**=经验本位、儿童本位；**社会中心**=社会本位、问题中心。

## 四、课程内容（三层次）⭐高频

| 层次 | 别称 | 内容 | 制定主体 |
|---|---|---|---|
| **课程计划** | 教学计划 | 对学校的教学、生产劳动、课外活动等的全面安排；规定**学科设置**、学科顺序、课时分配、学年编制等 | 国家教育行政部门 |
| **课程标准** | 教学大纲 | 每门学科以纲要的形式编订的指导性文件；规定学科的教学**目的与任务**、知识的范围、深度和结构等 | 国家教育行政部门 |
| **教材** | 教科书 | 依据课程标准编制的、系统反映学科内容的教学用书；是课程标准的具体化 | 专家/出版社 |

#### 三层次关系

> **课程计划**（宏观）→ **课程标准**（中观）→ **教材**（微观）
>
> 课程标准是**教材编写、教学、评估和考试命题的依据**，是国家管理和评价课程的**基础**。

## 五、课程设计·实施·评价

### 1. 课程设计模式

| 模式 | 代表人物 | 核心 |
|---|---|---|
| **目标模式** | **泰勒**（课程理论之父） | 确定目标→选择经验→组织经验→评价结果（**四环节**） |
| **过程模式** | 斯滕豪斯 | 关注教育过程而非预设目标 |

> 📌 泰勒的《**课程与教学的基本原理**》被誉为"课程理论的圣经"。

### 2. 课程实施取向

| 取向 | 要点 |
|---|---|
| **忠实取向** | 严格按课程计划执行 |
| **相互适应取向** | 课程计划与实际情境相互调整 |
| **创生取向** | 教师和学生在实践中共同创造课程 |

### 3. 课程评价模式

| 模式 | 代表人物 | 核心 |
|---|---|---|
| **目标评价模式** | 泰勒 | 以目标为评价标准（目标模式在评价上的应用） |
| **CIPP评价模式** | 斯塔弗尔比姆 | 背景→输入→过程→成果 |
| **目的游离模式** | 斯克里文 | 关注非预期效果 |

## 六、课程资源

- 课程资源是课程设计、实施和评价等整个课程编制过程中可利用的一切人力、物力和自然资源的总和
- **分类**：校内资源 vs 校外资源；素材性资源 vs 条件性资源；显性资源 vs 隐性资源
- **教材**是最基本的课程资源；**教师**是最重要的课程资源
- 师生关系是一种重要的**课程资源**和校园文化

## 七、高频考点速查

### 最爱考的对应关系

| 题目 | 答案 |
|---|---|
| 最早提出"课程"一词（中国） | 唐·**孔颖达** |
| 与现代"课程"含义最接近 | 宋·**朱熹** |
| 隐性课程提出者 | **杰克逊**《班级生活》 |
| 课程理论之父 | **泰勒**（目标模式/四环节） |
| 学科中心代表 | 夸美纽斯·赫尔巴特·斯宾塞·巴格莱 |
| 学生中心代表 | 杜威·克伯屈·罗杰斯 |
| 社会中心代表 | 布拉梅尔德 |
| 课程内容三层次（从宏观到微观） | 课程计划→课程标准→教材 |
| 课程标准的作用 | 教材编写、教学、评估和考试命题的**依据** |
| 课程计划的核心 | **学科设置** |
| 最基本的课程资源 | **教材** |
| 最重要的课程资源 | **教师** |

### 高频判断题陷阱

1. ❌"隐性课程就是非正式课程（不重要）"→隐性课程同样重要，潜移默化影响学生
2. ❌"最早提出课程的是朱熹"→最早是唐代**孔颖达**；与现代含义关联最大的是朱熹
3. ❌"课程标准=教学大纲（完全等同）"→课程标准是教学大纲的发展和完善
4. ❌"活动课程优于学科课程"→各有优点，应根据教育目标选择
5. ❌"课程即学科"→课程不仅包括学科，还包括活动、隐性课程等
