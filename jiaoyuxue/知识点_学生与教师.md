## 一、学生

### 1. 学生的特点 ⭐高频

| 维度 | 要点 |
|---|---|
| **学生是教育的对象**（从教师方面看） | 学生是教师的教育对象，是被教育者、被组织者和被领导者 |
| **学生是自我教育和发展的主体**（从学生自身特点看） | 学生具有**主观能动性**（自觉性/独立性/创造性三个层次）；学生是发展中的人，具有**可塑性**、**依赖性**和**向师性** |
| **学生是发展中的人** | 学生具有与成人不同的身心特点；具有发展的**巨大潜在可能性**；具有获得成人教育关怀的**需要** |

> 📌 **向师性**：学生入学后，教师会自然地成为他们亲近、信赖、尊敬甚至崇拜的对象——学生对教师有依赖感和模仿倾向。

### 2. 学生的主要权利 ⭐高频

| 权利类别 | 具体内容 |
|---|---|
| **受教育权**（最基本的权利） | ①参加教育教学活动的权利 ②获得奖学金/贷学金/助学金的权利 ③获得公正评价和相应学业证书的权利 ④提出申诉或依法提起诉讼的权利 |
| **人身权**（公民权利中最基本、最重要、内涵最丰富的权利） | ①**身心健康权**（生命健康/人身安全/心理健康） ②**人身自由权**（不受非法拘禁/搜查/逮捕） ③**人格尊严权**（不受侮辱/诽谤/歧视） ④**隐私权**（私人信息/私人领域不被侵犯） ⑤**名誉权**和**荣誉权** |
| 财产权 | 财产不受侵犯 |

### 3. 学生的义务

- 遵守法律法规
- 遵守学生行为规范，尊敬师长，养成良好的思想品德和行为习惯
- 努力学习，完成规定的学习任务
- 遵守所在学校或者其他教育机构的管理制度

## 二、教师

### 1. 教师职业概述

- 教师是履行教育教学职责的**专业人员**，承担教书育人、培养社会主义事业建设者和接班人、提高民族素质的使命
- 教师职业的产生与发展：教师作为一种职业，随着**学校**的产生而产生
- 《教师法》规定教师是**履行教育教学职责的专业人员**

### 2. ★教师的职业角色 ⭐高频

| 角色 | 要点 |
|---|---|
| **传道者** | 传授道德、价值观 |
| **授业解惑者** | 传授知识技能、解答疑惑 |
| **示范者**（榜样） | 言行举止对学生有示范作用 |
| **管理者** | 管理班级、组织教学活动 |
| **父母与朋友** | 关爱学生、与学生建立友好关系 |
| **研究者** | 研究教育教学、反思实践 |
| **心理辅导者** | 关注学生心理健康 |

### 3. 教师的形象

| 维度 | 要点 |
|---|---|
| 道德形象 | 最为基本的形象；为人师表、以身作则 |
| 文化形象 | 教师是知识的传授者、文化的传播者 |
| 能力形象 | 教育教学能力、组织管理能力等 |

### 4. ★教师劳动的特点 ⭐高频

| 特点 | 要点 |
|---|---|
| **示范性** | 教师的言行举止对学生具有榜样示范作用（"学高为师，身正为范"） |
| **创造性** | ①因材施教 ②教学方法上的不断更新 ③教育机智（对突发情况的应变能力） |
| **长期性** | 人才培养周期长；"十年树木，百年树人" |
| **复杂性** | ①教育目的的全面性 ②教育任务的多样性 ③劳动对象的差异性 |
| **空间的广延性和时间的连续性** | 劳动不受时空限制 |
| **主体性和示范性** | 教师的劳动手段就是教师自身 |
| **个体性和集体性** | 个体劳动+集体成果 |

#### 教育机智 ⭐

教师在教育教学过程中的一种特殊的**定向能力**，指教师对学生活动的敏感性，能根据学生新的特别是意外的情况，迅速而正确地作出判断，随机应变地采取恰当有效的教育措施解决问题的能力。

> 口诀记忆：教师劳动特点 = **示创长复广主个**

### 5. 教师威信

- 分类：**权力威信**（职权赋予）+ **信服威信**（人格和能力获得）
- 建立途径：培养自身良好的道德品质；培养良好的认知能力和性格特征；注重良好仪表和风度；做学生的朋友和知己

### 6. ★教师的职业素养 ⭐高频

| 素养 | 具体内容 |
|---|---|
| **道德素养**（职业道德） | ①**爱国守法** ②**爱岗敬业**（本质要求）③**关爱学生**（灵魂/核心）④**教书育人**（天职/根本任务）⑤**为人师表**（内在要求）⑥**终身学习**（不竭动力） |
| **知识素养** | ①**政治理论修养** ②**学科专业知识**（本体性知识）③**教育科学知识**（条件性知识—教育学/心理学）④**实践知识** ⑤**文化知识**（通识性知识） |
| **能力素养** | ①**语言表达能力** ②**教育教学能力** ③**组织管理能力** ④**自我调控和自我反思能力** ⑤**教育科研能力** |
| **心理素养** | 良好的心理品质、健康的人格、积极的心态 |

> 📌 口诀：**道德**（爱法敬教终身为）、**知识**（政学教文实）、**能力**（语教组调研）、**心理**

### 7. 教师专业发展 ⭐

| 维度 | 要点 |
|---|---|
| 概念 | 教师在整个专业生涯中，通过终身专业训练，习得教育专业知识技能，实施专业自主，表现专业道德，逐步提高自身从教素质，成为一位良好的教育工作者的专业成长过程 |
| **发展阶段** | ①**关注生存**（新手教师，关注人际关系）②**关注情境**（关注教学、成绩）③**关注学生**（成熟教师，关注学生个体差异） |
| 发展途径 | ①**观摩分析**优秀教师的教学 ②**微格教学** ③**专门训练** ④**教学反思**（波斯纳公式：经验+反思=成长） |

### 8. 教师的权利与义务

| 权利 | 义务 |
|---|---|
| 教育教学权（**最基本的权利**） | 遵守宪法、法律和职业道德 |
| 学术研究权 | 贯彻国家的教育方针 |
| 指导评价权 | 对学生进行宪法确定的基本原则的教育和爱国主义教育 |
| 获取报酬待遇权 | 关心爱护全体学生，尊重学生人格 |
| 参与学校管理权 | 制止有害于学生的行为 |
| 进修培训权 | 不断提高思想政治觉悟和教育教学业务水平 |

## 三、师生关系

### 1. 师生关系概述

- 师生关系是教育活动中最基本、最重要的**人际关系**
- 包括：**社会关系**、**教育关系**（最基本关系）、**心理关系**、**伦理关系**

### 2. 师生关系的基本类型 ⭐

| 类型 | 特点 |
|---|---|
| **专制型**（权威型） | 教师说了算，学生被动服从；课堂纪律好但学生缺乏创造性 |
| **放任型** | 教师不控制、不指导；学生纪律差、效率低 |
| **民主型** | 师生平等合作；课堂气氛活跃、学生积极性高、学习效果好 |

> 📌 **民主型**是最理想的师生关系类型。

### 3. 师生关系的内容

- **教学上的授受关系**：教师是传授者，学生是接受者
- **人格上的平等关系**：师生在人格上是平等的
- **社会道德上的相互促进关系**：师生在社会道德上相互影响、共同提高

### 4. ★建立新型师生关系 ⭐高频

| 要求 | 要点 |
|---|---|
| **尊师爱生** | 学生尊重教师，教师爱护学生 |
| **民主平等** | 师生在人格上平等、教学中民主 |
| **教学相长** | 教师的教和学生的学相互促进 |
| **心理相容** | 师生在心理上互相接纳、互相尊重 |

## 四、高频考点速查

### 最爱考的对应关系

| 题目 | 答案 |
|---|---|
| 学生最基本的权利 | **受教育权** |
| 公民权利中最基本、最重要的是 | **人身权** |
| 教师最基本的权利 | **教育教学权** |
| 教师职业道德的**核心/灵魂** | **关爱学生** |
| 教师的天职/根本任务 | **教书育人** |
| 教师职业的内在要求 | **为人师表** |
| 教师专业发展的不竭动力 | **终身学习** |
| 教师劳动最突出的特点 | **示范性** |
| 教育机智的体现 | **创造性** |
| 最理想的师生关系类型 | **民主型** |
| 师生关系中最基本的关系 | **教育关系** |
| 教师的知识素养中最重要的 | **学科专业知识**（本体性知识） |
| 教师的教育科学知识 | **条件性知识**（教育学/心理学） |
| 波斯纳教师成长公式 | **经验+反思=成长** |
| 教师关注生存→关注情境→关注学生 | 教师**专业发展三阶段** |
| 学生具有向师性→说明教师的劳动具有 | **示范性** |
| 学生是教育对象（从教师看） | 强调教师的**主导地位** |

### 高频判断题陷阱

1. ❌"学生最基本的权利是人身权"→是**受教育权**
2. ❌"教师的天职是关爱学生"→是**教书育人**；关爱学生是**灵魂/核心**
3. ❌"教师劳动最突出的特点是创造性"→是**示范性**；教育机智体现创造性
4. ❌"师生关系中最基本的是社会关系"→是**教育关系**
5. ❌"教师专业发展三阶段：关注学生→关注情境→关注生存"→顺序反了：**关注生存→关注情境→关注学生**
