## 一、德育概述

### 1. 德育的概念

| 类型 | 内容 |
|---|---|
| **广义的德育** | 所有有目的、有计划地对社会成员在政治、思想与道德等方面施加影响的活动（社会/社区/学校/家庭德育） |
| **狭义的德育** | 专指**学校德育** |

### 2. 德育的性质

| 性质 | 要点 |
|---|---|
| **历史性** | 德育的性质由一定社会的**经济基础**决定，随社会经济制度变革而变革 |
| **阶级性** | 不同社会制度下学校德育性质不同；阶级社会中的德育有阶级性 |
| **社会性** | 德育是各个社会共有的教育现象，与人类社会共始终 |
| **继承性** | 德育的原理、原则、内容和方法等存在一定的共同性 |

### 3. 德育的功能

| 功能 | 要点 |
|---|---|
| **个体性功能** | 促进个体的道德认识、情感、意志、行为发展 |
| **社会性功能** | 促进社会政治、经济、文化发展 |
| **教育性功能** | 德育对其他各育的促进作用 |

### 4. 德育目标与内容

- **德育目标**：德育活动预先设定的、通过德育活动使受教育者在思想品德方面达到的预期结果
- **我国学校德育内容**：政治教育、思想教育、道德教育、法制教育、心理健康教育

### 5. 独立德育学科标志

> **涂尔干《道德教育论》**的问世被视为德育作为一门独立学科产生的标志。荀子最早将"道""德"连用。

## 二、德育过程 ⭐

### 1. 德育过程与品德形成过程的关系

- **德育过程**：教育者按照一定的目的要求，有目的、有计划、有组织地对受教育者施加影响的过程（教育者主导）
- **品德形成过程**：个体自身品德发展的过程（个体内部矛盾运动）
- 德育过程是**品德形成过程**的一个方面；二者是教育与发展的关系

### 2. 德育过程的结构

教育者 + 受教育者 + 德育内容 + 德育方法（**四要素**）

### 3. 德育过程的基本矛盾

**教育者提出的德育要求与受教育者已有品德水平之间的矛盾**——德育过程的基本矛盾/主要矛盾。

### 4. ★德育过程的基本规律（四规律）⭐高频

| 规律 | 要点 |
|---|---|
| **德育过程是培养学生知、情、意、行的过程** | 知（认识）→情（情感）→意（意志）→行（行为）；**晓之以理、动之以情、持之以恒、导之以行**；行是衡量标准 |
| **德育过程是促进学生的思想品德内部矛盾积极转化的过程** | 激发品德发展动机是德育过程的**真正开端和起点** |
| **德育过程是组织学生的活动和交往的过程** | 活动和交往是德育过程的**基础**，也是学生思想品德形成和发展的**基础与源泉** |
| **德育过程是长期性、反复性、逐步提高的过程** | "两化"：社会道德**内化**为个体思想品德，个体品德**外化**为行为 |

> 📌 知情意行：品德发展的四个要素。**晓之以理**（知）**动之以情**（情）**持之以恒**（意）**导之以行**（行）。德育过程开端不一定从知开始。

## 四、★德育方法（六种）⭐高频

| 方法 | 要点 | 例子 |
|---|---|---|
| **说服教育法**（说理教育法） | **最基本/最常用**；语言说服（讲解/报告/谈话/讨论）+ 事实说服（参观/访问/调查） | 讲解道德规范 |
| **榜样示范法** | 以榜样人物的优良品德影响学生 | 学雷锋 |
| **实际锻炼法** | 组织学生参加实际活动，培养行为习惯 | 社会服务、值日 |
| **情感陶冶法**（陶冶教育法） | 创设情境，潜移默化 | 人格感化、环境陶冶、艺术陶冶 |
| **品德评价法**（奖惩法） | 表扬奖励、批评处分 | 操行评定 |
| **自我修养法** | 学生自我教育 | 座右铭、自我批评 |

> 📌 **说服教育法**是德育**最基本、最常用**的方法；榜样示范法以品德影响品德。

## 六、班主任与班级管理 ⭐

### 1. 班级与班级管理

- **班级**：学校为实现一定教育目的而组织起来的**基本单位**；是学生活动的**基本场所**
- 班级管理功能：**社会化功能** + 个体化功能（有利于学生自我管理能力培养）
- 班级管理过程：计划→组织→协调→控制
- 班级管理内容：班级组织建设、制度管理、教学管理、活动管理

### 2. ★班级管理模式 ⭐高频

| 模式 | 代表人物 | 要点 |
|---|---|---|
| **常规管理** | —— | 通过制定和执行规章制度管理班级 |
| **平行管理** | **马卡连柯** | 既通过集体影响个人，又通过个人影响集体 |
| **民主管理** | —— | 发挥学生主体作用，参与班级管理 |
| **目标管理** | **德鲁克** | 以班级目标为核心管理班级 |

### 3. ★班集体的培养 ⭐高频

| 维度 | 要点 |
|---|---|
| **特征** | ①明确的**共同目标**（基础）②健全的**组织**机构 ③严格的**规章制度** ④正确的**舆论**和良好的**班风** ⑤良好的人际关系 |
| **发展阶段** | 组建阶段→核心形成阶段→发展阶段→成熟阶段 |
| **培养方法** | ①确定班集体的**发展目标** ②建立班集体的**核心队伍** ③建立班集体的**正常秩序** ④组织形式多样的**教育活动** ⑤培养正确的**舆论**和良好的**班风** |

### 4. 班主任工作

- **班主任**：班集体的组织者、教育者和指导者；学校德育工作的骨干力量
- **班主任工作内容**：①了解和研究学生（**前提和基础**）②组织和培养班集体（**中心环节**）③协调各方教育力量 ④做好个别教育（先进生/后进生）⑤操行评定 ⑥写好班主任工作计划与总结
- 偶发事件处理：沉着冷静、机智果断

> 📌 班主任工作的**前提和基础**=了解和研究学生；**中心环节**=组织和培养班集体。

### 高频判断题陷阱

1. ❌"德育过程就是品德形成过程"→德育过程是教育过程，品德形成过程是自我发展过程，二者是教育与发展的关系
2. ❌"德育过程必须从知开始"→德育过程开端**不一定从知开始**（可从情、行等入手）
3. ❌"说服教育法就是讲道理"→说服教育包括**语言说服**（讲道理）和**事实说服**（参观访问等）
4. ❌"班主任工作的中心环节是了解学生"→了解和研究学生是**前提基础**，组织培养班集体才是**中心环节**
5. ❌"平行管理是德鲁克提出的"→平行管理是**马卡连柯**；德鲁克提出的是**目标管理**
