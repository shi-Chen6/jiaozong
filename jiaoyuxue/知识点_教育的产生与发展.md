## 一、教育的概述

### 1.1 教育的概念

#### （1）教育的日常用法（三种）⭐高频

| 用法 | 标志词 | 典型例子 |
|---|---|---|
| **过程**的教育（最基本用法） | "从…中""受…教育" | "我从这部影片中受到了一次深刻的教育" |
| **方法**的教育 | "怎么、如何" | "你是怎么教育孩子的" |
| **社会制度**的教育 | 官方文件用语 | "百年大计，教育为本""建国君民，教学为先" |

#### （2）教育的词源 ⭐高频

**中国：**
- "教育"一词最早见于 **《孟子·尽心上》**，最早将"教""育"**连用**的是**孟子**："得天下英才而教育之，三乐也"
- "教育"一词**解释**最早始于东汉 **许慎《说文解字》**："教，上所施，下所效也；育，养子使作善也"
- ⚠️ 易错：最早**合用**是孟子（战国），最早**解释**是许慎（东汉）

**西方：**
- "教育"源于拉丁文 **"Educare"**
- 前缀 "e-"：有"从出""引出"之意
- 词根 "ducare"：有"带领""引导"之意
- 含义：通过一定手段把潜在于身心内部的东西引发出来，从潜质转变为现实

**中西方词源对比（多选考点）：**

| | 中国 | 西方 |
|---|---|---|
| 教育理念 | 重视**外部力量的控制** | 重视**内在潜能的开发** |
| 秩序观 | 重视纪律秩序 | 重视自由个性 |
| 师生观 | 重视教师权威 | 重视儿童兴趣 |
| 经验观 | 重视直接经验 | 重视间接经验 |

#### （3）教育的定义 ⭐高频

**广义的教育**：凡是增进人的知识和技能、发展人的智力和体力、影响人的思想和品德的活动都是教育。

- 形式·版本一：学校教育、社会教育、家庭教育（**三合力**）
- 形式·版本二：
  - **学校教育**：核心/主导/主体形式（现代主要通过学校教育实现；金字塔形的等级制教育）
  - **社会教育**：教育的最早独立形态
  - **家庭教育**：基础；人一生中最早接受的教育
  - **自我教育**：教育的最特殊形式（随着社会发展，将逐渐成为教育的重心）
  - **自然形态的教育**：渗透在生产、生活过程中的口授身传（"生活的磨难教育了我们"）

**狭义的教育**：主要指学校教育——教育者根据一定的社会要求，有目的、有计划、有组织地对受教育者施加影响，促使他们朝着所期望方向发展的活动。

**更狭义的教育**：思想品德教育（德育）。

**个体角度**：教育等同于个体的学习或发展过程。

**综合性定义（兼顾个人和社会）**：教育是在一定社会背景下发生的促进个体社会化和社会个性化的实践活动。

**对比点（单选高频）：**
- 广义与狭义教育的**区分点**：计划性；**相同点**：目的性
- 学校教育与家庭/社会教育的主要区别：由专门机构和专职教职人员承担教育义务，有目的有计划有组织地开展系统教育活动
- 家庭教育、社会教育的影响结果具有：**偶然性和不确定性**
- 社会教育 vs 社区教育：一般不作区分，同时出现时首选**社会教育**
- ⚠️ 判断题陷阱："凡是能影响人的身心发展的活动都是教育"（**错**，必须加"从广义上说"）

#### （4）谢弗勒的教育定义分类 ⭐高频

美国分析教育哲学家谢弗勒（《教育的语言》）提出三种定义方式：

| 类型 | 含义 | 例子 |
|---|---|---|
| **规定性定义** | 作者自己创制的、内涵在特定话语情境中始终统一的定义 | "在本文中，我将教育定义为…一整套社会制度" |
| **描述性定义** | "实然/现实"，教育实际是怎么样的 | "教育是一种有意识的影响人身心发展的活动" |
| **纲领性定义** | "应然/理想"，教育应该是什么样的 | "教育是一种有目的地促进人的身心发展的活动" |

**教育术语 / 口号 / 隐喻（拔高题）：**
- **教育术语**（概念、范畴）：抽象化、概念化的语言
- **教育口号**：高度概括、旗帜鲜明、朗朗上口（"教育必须为无产阶级政治服务""计算机教育要从娃娃抓起"）
- **教育隐喻**（比喻）：介于术语和口号之间，来自感性认识（"教育即生长""教师是人类灵魂的工程师""玉不琢不成器"）

### 1.2 教育的结构 ⭐高频

#### （1）内部结构（基本要素）

**版本一（三要素）**：教育者、受教育者（学习者）、教育影响（教育中介系统/教育媒介/教育措施）
**版本二**：教育者与受教育者、教育内容与教育物资
**版本三**：教育者、受教育者、教育内容、教育手段

**教育者：**
- 定义：对受教育者在知识、技能、思想、品德等方面起到教育影响的人
- 地位：发挥**主导作用**，对青少年成长起**关键作用**；教育实践活动的主体
- 学校教师是教育者的主体，是最直接的教育者

**受教育者（学习者）：**
- 定义：参与教育活动，以期自身在各方面获得发展的人
- 地位：既是教育的**对象**，也是**学习的主体**；主体、根本因素、受教育的客体
- 教育的对象：由其**发展性和不成熟性**决定接受教育的必要性
- 学习的主体：由其**能动性和主体性**决定；学生作为学习主体的首要特征是**能动性**

**教育影响（教育中介系统/教育媒介/教育措施）：**
- 教育内容：教育者和受教育者**共同认识的客体**
- 教育手段：教育活动中采用的方式方法（黑板、粉笔、多媒体、教师语言等）
- 地位：教育者和受教育者的**中介、桥梁、媒介**，是中介的总和

**地位总结（拔高题）：**
- 主体：教师（教的主体）、学生（学的主体，首选）→ 师生为**复合主体**
- 客体：学生（教的客体）、教育内容（教和学的客体）→ 复合客体
- 中介纽带：教育影响（首选）、教育者
- 两个最基本的要素/主体性要素：**教育者和受教育者**（"双主体""复合主体""交互主体""复合主客体"）

**教育中的基本矛盾：**
- 三对基本矛盾：受教育者与教育内容 / 受教育者与教育者 / 教育者与教育内容
- **受教育者与教育内容的矛盾**是基本的、决定性的矛盾（是教育活动的逻辑起点）

#### （2）外部结构（教育系统的结构）

| 结构类型 | 内容 |
|---|---|
| 教育层次结构（级别体系、程度结构） | 学前教育、初等教育、中等教育、高等教育 |
| 教育类型结构 | 普通教育、职业教育、其他（如国防教育） |
| 办学形式结构 | 全日制、半工（农）半读学校、业余学校、函授、刊授、广播、电视等 |
| 教育管理体制结构 | 公办、民办、社会团体办、企业事业办、私人办学 |

### 1.3 教育的本质 ⭐高频

- 教育的本质回答的是**教育是什么**的问题，是教育学理论体系建构的基石
- 核心表述：**教育是一种有目的地培养人的社会实践活动**——是教育区别于其他事物现象的根本特征，是教育的**质的规定性**
- 理解：有目的（非本能、非偶然）、培养人（人类社会特有、多为正向的）、社会实践活动（是社会活动，也是实践活动，**单选首选社会活动**）

**对比点：**
| 概念 | 答案 |
|---|---|
| 教育的本质属性 | **育人性** |
| 教育的根本属性 | **社会性** |
| 人的教育活动与动物的"教育"活动的本质区别 | **社会性和意识性** |
| 人的实践活动与动物的本能活动的根本区别 | **目的性** |

**本质特点的三种版本表述：**
- 版本一：教育是人类社会所特有的有意识的活动；教育是人类有意识地传递社会经验的活动；教育是以培养人为直接目标的社会实践活动
- 版本二：有目的地培养人的活动（最主要）；教育者引导受教育者传承经验的互动活动；激励与教导受教育者自觉学习和自我教育的活动
- 版本三：①教育是人类独有的社会现象 ②教育是有意识、有目的、自觉的培养过程 ③存在教育者、受教育者、教育影响三要素的相互关系

**教育本质的其他学说：**
| 学说 | 要点 |
|---|---|
| 生产力说（现代派） | 教育是国民经济的重要组成部分，是劳动力再生产的手段和必要条件 |
| 上层建筑说（传统派） | 教育是培养思想品德、传授知识技能的工作，属于社会意识形态范畴 |
| 双重属性说 | 教育既属于上层建筑，又属于生产力 |
| 多质说 | 教育本质是多质、多层次的（社会性、生产性、阶级性、科学性、艺术性的统一） |
| 特殊范畴说 | 教育是独特的社会现象，是特殊的社会范畴 |

### 1.4 教育的社会属性 ⭐高频

| 属性 | 要点 | 例子/提示 |
|---|---|---|
| **永恒性** | 教育与人类社会共始终 | 杨贤江"自有人生，便有教育"；决定永恒性的是教育的**功能（职能）** |
| **历史性** | 不同社会或同一社会不同历史阶段，教育性质、目的、内容不同（包含时代性） | "罢黜百家，独尊儒术" |
| **阶级性** | 在阶级社会里教育都具有阶级性；原始社会和共产主义社会无阶级性 | "学在官府"；古印度四个阶层 |
| **相对独立性** | 教育受社会制约（相对性），又有自身运行规律（独立性） | 不存在"超政治""超阶级"的教育 |
| 长期性 | "十年树木，百年树人" | |
| 生产性 | 教育从来就是生产性活动 | "今天的教育就是明天的经济" |
| 民族性 | 教育在具体的民族或国家中进行 | 中国特色社会主义教育 |
| 迟效性 | 教育投资不能立刻见效 | 长期性与迟效性单选一般不同时出现 |
| 社会性 | 教育的社会制约性是教育社会性最主要的表现形式 | |

**相对独立性的表现（版本多，不可混选）：**
- 版本一：教育具有质的规定性（教育是培养人的社会实践）；教育具有历史继承性（古今相同）；与生产力并非完全同步（不平衡性，超前：经济要发展教育要先行）；与政治经济制度的变革并非完全同步
- 版本二（王道俊）：教育是一种转化活动的过程；历史继承性；教育与社会政治经济发展不平衡
- 版本三：历史继承性；不平衡性；与其他社会意识形式的平行性；教育要受其他社会意识形态的影响
- 版本四：教育要受其他社会意识形态的影响；教育具有自身的继承关系；教育与社会政治经济发展不平衡
- 版本五：教育是培养人的活动；教育具有自身的传统与连续性；教育具有自身的活动特点、规律及原理

**不同社会阶级性/等级性对照表：**

| 社会 | 阶级性 | 等级性 |
|---|---|---|
| 原始社会 | 无 | 无 |
| 奴隶社会 | 有（鲜明） | 有（鲜明） |
| 封建社会 | 有（鲜明） | 有（鲜明） |
| 资本主义社会 | 有 | 无（等级性消失） |
| 社会主义社会 | 有 | 无 |

### 1.5 教育的功能 ⭐高频

**本质 vs 功能：** 本质回答"教育是什么"，功能回答"教育能够干什么"。

#### （1）特征（5个）
**客观性**（由教育本质和教育系统的结构决定，单选首选**结构**）、**社会性**、**多样性**、**整体性**（有序组合体）、**条件性**（功能不会自动实现，具有潜在性）。

#### （2）类型（5种分类）⭐高频

| 划分标准 | 类型 |
|---|---|
| 按作用的对象 | 个体发展功能（本体功能/固有功能）、社会发展功能（派生/工具/衍生功能） |
| 按作用的性质（方向） | 正向功能（积极功能）、负向功能（消极功能） |
| 按呈现的形式（表面属性/外部特征） | 显性功能、隐性功能（主要区别是**计划性**） |
| 按教育的性质 | 保守功能、超越功能 |
| 按作用的客观性能 | 筛选功能、协调功能 |

**个体功能：**
- 个体社会化功能（教育的最首要、最基本功能）：促进个体思想意识社会化、行为社会化，培养职业意识和角色（版本二：形成社会价值观、完善自我观念、掌握社会技能、塑造社会角色）
- 个体个性化功能：促进主体意识形成和主体能力发展，促进个体差异充分发展形成独特性，促使创造性开发并实现个体价值（版本二：唤醒生命自觉、尊重个体差异性和独特性、促进个性和创造性的发展）

**社会功能（社会变迁功能）：**
| 功能 | 定位 |
|---|---|
| 政治功能 | 社会功能中最**直接** |
| 经济功能 | 社会功能中最**基础** |
| 文化功能 | 与人类社会共始终 |
| 生态功能（环境功能） | 保护自然环境、促进可持续发展 |
| 科技功能、人口功能 | |
| 社会流动功能 | 横向流动（水平：更换工作地点单位任务）；纵向流动（垂直：职称晋升、职务升迁、薪酬提级，"朝为田舍郎，暮登天子堂"） |

**正向/负向功能：**
- 负向功能原因：教育与政治经济发展不相适应、教育者价值观念与思维方式不正确、教育内部结构不合理等
- 克服负向功能的关键：树立"以人为本"的教育理念

**显性/隐性功能：**
- 显性：依照教育目的，实际运行中出现的与之相吻合的结果（促进人的全面和谐发展、促进社会进步）
- 隐性：伴随显性功能出现的非预期性功能（教育复制现有社会关系、再现社会不平等、学校照管儿童）
- 二者可以相互转化；隐性功能不等于负向功能（隐性中既有积极也有消极）

**保守/超越功能：**
- 保守：教育具有自身结构，内在稳定性和逻辑性，不随社会变化而变化（"教育的基本功能之一就是重复…"）
- 超越：通过教育的自我更新和变革，促进和引领人类社会发展

**筛选/协调功能：**
- 筛选：很大程度上是竞争和选拔的过程
- 协调：通过教育尽量缩小人与人之间的发展差异

**拓展（柴野昌山，日本学者）：** 正向显性、正向隐性、负向显性、负向隐性四象限。

## 二、教育的起源 ⭐高频（七大起源学说）

| 学说 | 代表人物 | 核心观点 | 地位/要点 |
|---|---|---|---|
| **神话起源说** | 所有宗教、朱熹 | 教育由人格化的神（上帝或天）创造，体现神或上天的意志 | 最古老的观点 |
| **生物起源说** | 沛西·能、利托尔诺、桑代克 | 教育的产生完全来自动物的生存本能 | ①第一个正式提出的教育起源学说 ②标志从神话转向科学解释 ③理论基础：达尔文生物进化论 ④利托尔诺最早把教育起源作为学术问题研究 ⑤两者（与心理起源）共同忽视了教育的社会性和目的性（单选首选**社会性**） |
| **心理（模仿）起源说** | 孟禄（美） | 教育起源于日常生活中儿童对成人的**无意识模仿** | |
| **劳动起源说**（社会起源说） | 米丁斯基、凯洛夫、巴拉诺夫 | 教育起源于劳动过程中社会生产需要和人的发展需要的辩证统一 | 唯一科学的起源学说；理论基础：恩格斯《劳动在从猿到人转变过程中的作用》 |
| **需要起源说** | 杨贤江 | 教育起源于社会生活实际的多方面需要 | |
| **交往起源说** | 叶澜 | 教育形态只能起源于人与人之间的交往 | |

## 三、教育的发展历程

### 3.1 原始社会的教育

**基本特征（超格提示口诀）：** 非独立性、自发性、全民性、广泛性、**无阶级性、无等级性**、原始性

- ①教育具有自发性、广泛性、无等级性和无阶级性（体现全民性）；教育权平等，对儿童实行**公养公育**
- ②教育主要是为**生产劳动**服务的
- ③教育在整个社会生产和生活中进行，尚未从社会生产和生活中分化出来（**非独立性**）
- ④教育手段极端原始，内容简单、方法单一；教育与冠礼、祭祀、图腾崇拜等原始宗教仪式紧密联系（**原始性**）

### 3.2 古代社会的教育

#### （1）学校与学校产生条件 ⭐高频

| 考点 | 答案 |
|---|---|
| 教育形成相对独立形态的标志 | **学校的出现** |
| 学校教育最早产生于 | **奴隶社会初期** |
| 我国最早的学校产生于 | **夏朝**（庠）；中国有史可考-夏，考古发现证明-商 |
| 世界上最早的学校 | 古埃及宫廷学校（公元前2500年，有史可考）；古巴比伦泥板书屋（考古发掘） |
| 我国最早的小学产生于 | 商代（殷周） |

**学校产生的条件：**
- 版本一：物质基础=社会生产水平的提高；历史基础=国家的产生；客观条件=体脑分工和专职教师的出现；重要标志=文字的创造和知识经验的积累
- 版本二（基本条件）：社会需要、剩余劳动力、文字（重要标志）
- 版本三：生产力的发展水平、生产经验和生活经验的积累、奴隶制国家巩固政权的需要、体脑分工及剩余劳动力的出现、文字的出现和生产生活经验的积累

#### （2）古代教育基本特征 ⭐高频

- **教育与生产劳动相脱离，具有非生产性**（"樊迟请稼"孔子；"劳心者治人，劳力者治于人"孟子）——教育与生产劳动的关系：**结合（原始）-分离（古代）-结合（现代）**；从分离走向结合始于**资本主义社会**，紧密结合在**社会主义社会**；学校教育与生产劳动相脱离始于**奴隶社会**
- **阶级性和等级性**：阶级性=阶级与阶级之间（学在官府；古印度种姓制度）；等级性=阶级内部（六学二馆；九品中正制"上品无寒门，下品无士族"）——等级性是中国**封建社会**最显著的教育特征
- **道统、专制、刻板、象征**（思想文化）：道统性=教育内容是统治阶级的政治思想和伦理观念；专制性=管制与被管制、灌输与被动接受；刻板性=死记硬背、机械模仿；象征性=接受什么教育标志一个人的社会地位
- 官学与私学并行的教育体制；尚未形成复杂的结构体系；教学组织形式主要是个别施教

#### （3）中国奴隶社会的教育（夏商西周春秋）

| 时期 | 要点 |
|---|---|
| **夏商** | 教育场所：庠、序、校、大学、小学、瞽宗等；教育目的：培养能射善战的武士；教育内容：军事训练（习射为重点）+宗教教育（敬天尊祖为中心）；我国最早学校产生于夏朝，最早小学产生于商朝 |
| **西周** | 教育内容：**六艺**（礼乐射御书数，中心是**礼乐**；大艺=礼乐射御，小艺=书数；乐重在陶冶内在精神情操，礼是外在行为规范）；六艺是**学科课程**的雏形；教育特征：**学在官府、官师合一**（"惟官有书，而民无书…"）；天子大学=辟雍，诸侯大学=泮宫；考核制度"一三五七九"（《学记》"比年入学，中年考校…"）；最早的儿童识字课本《史籀篇》 |
| **春秋** | **私学兴起，官学衰微**（孔子私学最有名）；百家争鸣，以儒墨两家为主的显学盛行 |

### 3.3 近代社会的教育

#### （1）近代社会基本特征 ⭐高频

1. 国家加强了对教育的重视和干预，**公立教育崛起**
2. **初等义务教育的普遍实施**（最早提出义务教育概念：16世纪德国马丁·路德；世界上最早实施义务教育的国家：**德国**）
3. 重视教育立法，倡导以法治教
4. 教育的**世俗化**（教育摆脱宗教）
5. 形成了较系统的近代学校教育制度，出现了**双轨制**

#### （2）外国近代教育 ⭐高频

| 阶段 | 代表人物 | 要点 |
|---|---|---|
| **文艺复兴时期·人文主义教育** | 维多利诺、伊拉斯谟 | 赞扬人的价值和尊严，宣扬思想解放和个性自由，提倡学术，尊崇理性 |
| **宗教改革时期·新教教育** | 路德派（马丁·路德最早提出义务教育概念）、加尔文（**普及教育之父**）、英国国教 | 国家推行普及教育思想 |
| **宗教改革时期·天主教教育** | 罗耀拉 | 重视中等教育和高等教育 |
| **19世纪欧美主要国家** | | 德国《初等义务教育法》、法国《费里法案》（义务、免费、世俗化三大原则）、英国《初等教育法》（福斯特法案）、美国强迫义务教育法；**赫拉斯·曼**：美国公立学校教育之父、教育机会均等理念 |

#### （3）中国近代教育 ⭐高频

**洋务运动时期（鸦片战争）：**
- 指导思想："**中学为体，西学为用**"（该思想最早由冯桂芬1861年提出，最早系统论证：张之洞《劝学篇》）；西学=新学=西政、西艺、西史
- 创办新式学堂：外国语学堂=**京师同文馆**（1862年，我国成立最早的学堂、第一所外国语学堂、最早推行班级授课制）；工业技术学堂（上海机械学堂、天津电报学堂，求富）；军事学堂（天津水师学堂、福建船政学堂，自强）；留学教育（留美幼童、留欧学生）
- 意义：洋务教育具有封建性和买办性，是**中国半殖民地半封建教育的开端**
- 对比点：近代中国最能体现半殖民地半封建社会性质的学校：**教会学校**

**维新运动时期（甲午中日战争）：**
- 设立**京师大学堂**（1898年，北大前身）；废除八股考试、改革科举制度；普遍建立新式学堂
- 代表人物：**梁启超**（《变法通议》首次专门论述师范教育；重视女子教育，创办经正女学；倡导趣味教学"乐知"）；**严复**（从德智体三要素构建教育目标模式第一人；倡导"体用一致"文化教育观）

**清末新政时期（八国联军侵华）：**
- 清末学制的建立：**壬寅学制、癸卯学制**
- **1905年正式废除科举制**；废科举，兴学堂
- 教育宗旨："忠君、尊孔、尚公、尚武、尚实"（中国近代第一次正式宣布的教育宗旨）
- 留学教育：留日、留美（退款兴学）

**20年代的教育思潮与教育改革运动：** 平民、工读、职业、实用主义、勤工俭学、科学教育等思潮。

**易错辨析：** 京师同文馆建于洋务运动；京师大学堂建于维新运动；八股文废除于维新运动；科举制废除于清末新政；最早公立小学=南洋公学外院；最早师范院校=南洋公学师范院。

#### （4）近代教育的代表人物 ⭐高频

**蔡元培：**
- 称号：被毛泽东称为"学界泰斗，人世楷模"；20世纪初中国资本主义教育制度的创始者
- **五育并举**：军国民教育（体育，急务）、实利主义教育（智育，教育与经济的关系）、公民道德教育（德育，**核心和重点**）、世界观教育（**最高境界**，超越政治的教育）、美感教育（**中介和桥梁**；近代第一次将美育列入教育方针，提出"以美育代宗教"）
- 教育最终目的：使公民具有健全的人格
- 北大改革实践：抱定宗旨改变校风（"大学者，研究高深学问者也"）；"思想自由，兼容并包"（**核心灵魂**）；教授治校民主管理；学科与教学体制改革（废科设系、改年级制为选科制）；"与其守成法，毋宁尚自然；与其求划一，毋宁展个性"
- 教育独立思想：经费、行政、学术与内容、脱离宗教而独立
- ⚠️ 对比：近代最早提出"美育"这一教育目标的是**蔡元培**（1912）；首次明确提出"美育"一词的是**王国维**（最早提出德智体美全面发展）；世界最早提出美育一词的是**席勒**

**晏阳初（平民教育）：**
- 称号："国际平民教育之父"
- 在河北定县开展实验；四大教育：文艺教育攻"愚"培养知识力、生计教育攻"穷"培养生产力、卫生教育攻"弱"培养强健力、公民教育攻"私"培养团结力（**公民教育最为根本**）
- 三大方式：学校式教育、社会式教育、家庭式教育
- 核心思想："欲化农民，必先农民化"（博士下乡）

**梁漱溟（乡村教育）：**
- 称号：乡村教育之父
- 中国问题的原因：社会文化的失衡
- 立足文化传统，创造新文化救活旧农村；建立乡农学校、设立乡农教育课程（山东邹平、菏泽、济宁）

**黄炎培（职业教育）：**
- 称号："职业教育之父"
- 教育要旨：为个人谋生之准备、为个人服务社会之准备、为世界国家增进生产力之准备
- 教育目的（20世纪20年代后）：**使无业者有业，使有业者乐业**
- 教育方针：社会化、科学化；教育原则："手脑并用""做学合一"；职业道德教育：敬业乐群

**陈鹤琴（幼儿教育）：**
- 称号："中国幼教之父""中国的福禄贝尔""儿童教育的圣人"；我国最早使用日记描述法的教育家（世界幼教之父=福禄贝尔）
- 教育实践：创办中国第一所实验幼稚园=南京鼓楼幼稚园；第一所公立幼稚师范学校=江西省立幼师（中国第一所幼稚园=湖北幼稚园）
- "活教育"思想体系：目的论（做人、做中国人、做现代中国人）；课程论（"大自然、大社会都是活教材"；五指活动：文学、艺术、科学、健康、社会，体现儿童身心发展的整体性）；教学论（做中教、做中学、做中求进步；教学步骤：实验观察→阅读思考→创作发表→批评研讨，第一步和最重要的一步是**实验观察**）

**陶行知（生活教育）：**
- 称号：毛泽东称"伟大的人民教育家"；宋庆龄称"万世师表"；周恩来称"毫无保留追随党的党外布尔什维克"；郭沫若"两千年前孔仲尼，两千年后陶行知"
- 培养目标：新教育培养全面发展的"人中人"（反对旧教育培养"人上人"）
- 教育实践：1927年创办晓庄师范（确立生活教育思想；第一个乡村幼稚园=燕子矶幼稚园；教师培养方式=**艺友制**）；1932年创办山海工学团（首创"小先生制"，即知即传）；1934年发表《行知行》，提出"行是知之始，知是行之成"；1939年创办育才学校（重视创造精神）；1946年创办社会大学
- **"生活教育"理论三大主张**：**生活即教育**（理论核心：生活含有教育的意义，实际生活是教育的中心，生活决定教育、教育改造生活）；**社会即学校**（以社会为学校、学校含有社会的意味）；**教学做合一**（教学方法的具体化，做是核心；在劳力上劳心、行是知之始、反对注入式教学）
- 儿童教育理论：六大解放（解放儿童的头脑、双手、嘴、眼睛、时间和空间）
- 名言： "捧着一颗心来，不带半根草去"（道德素养）；"出世便是破蒙，进棺才算毕业"（终身教育）；"千教万教教人求真，千学万学学做真人"；"你的教鞭下有瓦特，你的冷眼里有牛顿，你的讥笑中有爱迪生"（关爱学生/因材施教）；"接知如接枝"（间接经验与直接经验相统一）；"嫩枝易弯也易直"（可塑性）；"活到老，干到老，学到老"（终身教育）

### 3.4 现代社会的教育 ⭐高频

#### （1）教育的终身化 ⭐高频

- 概念：人们在一生中都应当和需要受到各种教育培养的总和（甚至可以追溯到胎教）；是适应科学知识加速增长和人的持续发展要求而形成的教育思想和教育制度
- 本质特征：（纵向）贯穿人生始终，具有时间延展性；（横向）包括所有现存教育形态在内的教育过程，更多是一种教育理论和教育观念
- **发展脉络**：
  - 最早产生：1929年**耶克斯利**出版世界上第一本终身教育专著《终身教育》
  - 概念化和体系化：1965年**保罗·朗格朗**《论终身教育》报告书发表；1970年出版《终身教育导论》
  - 1972年《学会生存——教育世界的今天和明天》（埃德加·富尔）提出学习型社会和终身教育概念
  - 最终形成：1996年联合国教科文组织报告《教育——财富蕴藏其中》，确立"4个支柱"：学会认知、学会做事、学会共同生活（学会合作）、学会生存；2003年增加"学会改变"成为5个支柱
- 地位：当代国际社会中影响最大、传播最广、最具生命力的一种教育思潮；被认为是知识社会的根本原理；发达国家制定教育政策的主导思想
- 最大特征：**终身性**；基本特征和原则：终身性、全民性（普及性）、广泛性、灵活性和实用性
- 当代最具影响力的两大教育思潮：**终身教育和全民教育**

#### （2）教育的全民化/民主化/多元化/现代化/信息化（21世纪教育特征："全民信个球"）

| 趋势 | 要点 |
|---|---|
| **全民化** | 人人都有接受教育的权利，且必须接受一定程度的教育 |
| **民主化** | 现代教育最显著的发展特征；教育民主化的中心内容是实现**教育平等**（教育机会均等是基础，是最高意义上的公平）；对教育等级化、特权化和专制性的否定；既追求所有人受同样教育，又追求教育的自由化；教育机会均等（起点/过程/结果均等论，胡森） |
| **多元化** | 对教育单一性和统一性的否定；是社会生活的多元化和人的个性化要求在教育上的反映 |
| **现代化** | 核心=**人的现代化**（教育现代化的最高目的、终极目标）；教育内容和方法的现代化=核心与衡量标准（有的说法：核心=教育内容和方法现代化）；**教师队伍的现代化=关键**；教育制度现代化=着力点；教育条件设备现代化=反映教育教学水平的重要标志 |
| **信息化** | 技术层面：数字化、网络化、智能化、共享化、多媒体化、自动化、虚拟化；教育层面：开放性、共享性、交互性、协作性、自主性、多样性；教育智能化是教育信息化发展的新阶段 |

**现代教育的特征（多版本，不可混选）：**
- 版本一：公共性（大众服务）、生产性（面向现代化）、科学性、未来性、国际性、终身性
- 版本二：学校教育逐渐普及、教育的生产性不断增强、教育的公共性不断增强、教育制度逐步完善
- 版本三：商品性、生产性、科学性、民主性、发展性
- 版本四：培养全面发展的人由理想走向实践；教育与生产劳动相结合日趋密切；教育普及制度化、形式手段多样化；教育实施的法制化和民主化；人文教育与科学教育携手并进；教育日益显示出开放性和整体性

#### （3）不同社会教育的特征对比

| 社会 | 教育特征 |
|---|---|
| 原始社会 | ①教育水平低 ②没有阶级性 ③教育与原始宗教或仪式紧密联系 |
| 奴隶社会 | ①古代学校出现 ②教育阶级性的出现 ③学校教育与生产劳动相脱离 |
| 封建社会 | ①目的：培养官吏、牧师或骑士 ②既具鲜明阶级性，又具严格等级性或浓厚宗教性 ③内容以道德文章或宗教经典为主 ④方法以严格纪律约束为主，辅以自学修行 ⑤形成比较系统的教育体系 |
| 资本主义社会 | ①教育目的兼顾各阶层需要 ②建立体系完备的现代学校制度 ③师生关系民主化 ④课程结构内容不断调整 ⑤独立形态的教育学产生并极大发展 |
| 社会主义社会 | ①目的：培养社会主义公民和建设人才 ②**教育与生产劳动相结合** ③教育科学研究有了科学方法论基础 |

### 4.2 高频判断题陷阱

1. ❌"凡是能影响人的身心发展的活动都是教育"——必须加"从广义上说"
2. ❌"教育概念最早见于《论语》"——应是最早见于《孟子·尽心上》
3. ❌"东汉许慎最早把'教''育'合成一词进行解释"——合成一词连用的是孟子，许慎是解释
4. ❌"生物起源说主要代表人物是孟禄"——孟禄是心理起源说
5. ❌"第一个正式提出的是神话起源学说"——第一个正式提出的是生物起源说
6. ❌"最古老的起源学说是生物起源说"——最古老的是神话起源说
7. ❌"教育现象最早产生于奴隶社会"——原始社会就有教育
8. ❌"教育促进社会发展的功能是教育的本体功能"——本体功能是个体发展功能
9. ❌"教育功能回答教育是什么的问题"——本质回答是什么，功能回答能干什么
10. ❌"教育将随国家的消亡而消亡"——教育具有永恒性
11. ❌"春秋时期的稷下学宫是官办学府"——稷下学宫是战国时期、官家举办私家主持
12. ❌"晓庄师范学校是陈鹤琴创办的"——是陶行知创办的
13. ❌"教育即生活/学校即社会"是陶行知提出的——这是杜威的主张；陶行知是"生活即教育/社会即学校"
14. ❌"家庭教育不具有目的性"——家庭教育具有目的性，但与学校教育相比影响结果具有偶然性和不确定性
