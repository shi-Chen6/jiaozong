## 一、教学概述

### 1. 教学的概念与意义

- **教学**：教师的教和学生的学共同组成的**双边活动**；以**课程内容**为中介；是学校的**中心工作**
- 教学的地位：教学是学校的**中心工作**，学校工作必须**以教学为主**
- 教学与教育：教学是教育的基本途径；教育包括教学、课外活动、班主任工作等

### 2. 教学的本质 ⭐

| 观点 | 要点 |
|---|---|
| **教学是特殊认识活动**（主流观点） | 教学过程是学生的**认识过程**，但不同于一般认识，具有特殊性：间接性、引导性、简捷性 |
| 教学是双边活动 | 教与学相互依存、相互促进 |

## 二、★教学过程 ⭐高频

### 1. 教学过程的本质

教学过程是教师依据一定社会的教育要求和学生身心发展规律，**引导学生积极主动地掌握知识、发展智力、培养能力、形成品德**的过程。是师生共同活动的过程，是**特殊的认识过程**。

### 2. ★教学过程四大基本规律

| 规律 | 内涵 | 教学启示 |
|---|---|---|
| **间接经验与直接经验相统一**（间接性规律） | 学生以学习**间接经验**为主；间接经验以直接经验为基础 | "闻之不若见之"；理论联系实际 |
| **掌握知识与发展智力相统一**（发展性规律） | 知识是发展智力的**基础**；发展智力是掌握知识的**必要条件** | 防止"高分低能"和"为发展而发展" |
| **教师主导作用与学生主体作用相统一**（双边性规律） | 教师主导与学生主体辩证统一 | 防止"教师中心"和"儿童中心"两个极端 |
| **传授知识与思想教育相统一**（教育性规律） | 知识是思想品德形成的**基础**；思想品德是知识学习的**动力** | 教学永远具有教育性（赫尔巴特） |

### 3. 教学过程的基本阶段

**激发学习动机→感知教材→理解教材（中心环节）→巩固知识→运用知识→检查知识**

> 📌 理解教材是教学过程的**中心环节**；感知教材是基础。

## 三、★教学原则（八大原则）⭐高频

| 原则 | 代表人物/名言 | 贯彻要求 | 古语/例子 |
|---|---|---|---|
| **直观性原则** | 夸美纽斯（"凡是需要知道的事物都要通过事物本身来教学"） | 正确选择直观教具；直观与讲解结合 | "不闻不若闻之，闻之不若见之" |
| **启发性原则** | 孔子（"不愤不启，不悱不发"）·苏格拉底（产婆术）·《学记》（"道而弗牵"） | 调动学生主动性；启发学生独立思考 | 第一个提出者是孔子（中国）/苏格拉底（西方） |
| **巩固性原则** | 孔子（"温故而知新"）·乌申斯基（"复习是学习之母"） | 在理解基础上巩固；组织好复习 | 夸美纽斯"教与学的巩固性原则" |
| **循序渐进原则** | 《学记》（"不陵节而施""学不躐等"）·朱熹（"循序而渐进"） | 按教材系统性教学；抓主要矛盾 | "欲速则不达""盈科后进" |
| **因材施教原则** | 孔子（"视其所以，观其所由"） | 针对学生特点进行有区别的教学 | "一把钥匙开一把锁" |
| **理论联系实际原则** | 陶行知（"教学做合一"） | 书本知识与生活实践结合 | "纸上得来终觉浅，绝知此事要躬行" |
| **量力性原则**（可接受性） | 墨子（"深其深，浅其浅"）·王阳明（"随人分限所及"） | 教学要符合学生发展水平 | "语之而不知，虽舍之可也" |
| **科学性与教育性统一** | 赫尔巴特（教育性教学） | 知识教学与思想教育统一 | 传授科学知识与思想品德教育结合 |

#### 八大原则口诀

> **直启巩循，因理量科**（直观·启发·巩固·循序渐进·因材施教·理论联系实际·量力·科学性与教育性）

| 名言 | 原则 |
|---|---|

| "道而弗牵，强而弗抑，开而弗达" | **启发性** |

| "深其深，浅其浅""随人分限所及" | **量力性** |
| "一把钥匙开一把锁" | **因材施教** |

## 四、★教学方法 ⭐高频

### 1. 以语言传递为主

| 方法 | 要点 | 备注 |
|---|---|---|
| **讲授法** | 教师用口头语言系统传授知识 | **应用最广泛**的基本方法；包括讲述、讲解、讲读、讲演 |
| **谈话法**（问答法） | 师生问答互动 | 苏格拉底产婆术 |
| **讨论法** | 学生围绕问题讨论 | 需要一定知识基础 |
| **读书指导法** | 指导学生自学教材、参考书 | —— |

### 2. 以直观感知为主

| 方法 | 要点 |
|---|---|
| **演示法** | 教师展示实物、教具、示范实验 |
| **参观法** | 组织学生到校外实地观察 |

### 3. 以实际训练为主

| 方法 | 要点 |
|---|---|
| **练习法** | 应用知识形成技能技巧（各科普遍使用） |
| **实验法** | 学生在教师指导下独立操作（理化生） |
| **实习作业法** | 在实习场所运用知识（生产技术课） |
| **实践活动法** | 组织学生参加社会实践 |

### 4. 以情感陶冶为主

**欣赏教学法**（艺术美/自然美/社会美欣赏）+ **情境教学法**（创设情境，如"李吉林情境教学"）。

### 5. 国内外教学方法改革

| 国内 | 国外 |
|---|---|
| 尝试教学法（邱学华）、情境教学法（李吉林）、愉快教学法、成功教学法 | **发现法**（布鲁纳）、**掌握学习法**（布卢姆）、**范例教学法**（瓦根舍因）、**暗示教学法**（洛扎诺夫）、**纲要信号图示法**（沙塔洛夫） |

## 五、★教学组织形式 ⭐高频

### 1. 班级授课制（基本组织形式）

| 维度 | 要点 |
|---|---|
| **概念** | 把学生按年龄和知识程度编成固定班级，按课程表统一教学 |
| **产生** | 最早产生于**16世纪西欧**；**夸美纽斯**在《大教学论》中系统论述（理论奠基） |
| **传入中国** | 1862年**京师同文馆**最早采用 |
| **特点** | 班（固定班级）课（按课表）时（固定课时）；以**课时**为单位 |
| **优点** | 高效率、大面积培养人才；教师主导 |
| **缺点** | 不利于因材施教、不利于发展个性、缺乏灵活性 |

### 2. 其他组织形式

| 形式 | 要点 |
|---|---|
| **个别教学** | 最古老的组织形式；古代教育基本形式 |
| **分组教学** | 按能力或成绩分组（内部分组/外部分组） |
| **道尔顿制** | 帕克赫斯特；教师指定作业，学生自学，废除课堂教学 |
| **设计教学法** | 克伯屈；学生自己设计、自己实行 |
| **特朗普制**（灵活的课程表） | 大班上课（40%）+小班研究（20%）+个别教学（40%） |
| **复式教学** | 一位教师、同一节课、不同年级；直接教学与自动作业交替（农村教学点） |

> 📌 **特朗普制**口诀："大4小2个4"；复式教学是班级授课制的**特殊形式**。

## 六、★教学工作基本环节 ⭐高频

| 环节 | 地位 | 要点 |
|---|---|---|
| **备课** | **前提/基础** | 备教材（吃透教材）·备学生（了解学生）·备教法（设计教法）；写好**三种计划**：学期/单元/课时计划；教案核心 |
| **上课** | **中心环节** | 一堂好课标准：目标明确、内容正确、方法得当、组织严密、气氛热烈、语言艺术 |
| **课外作业的布置与批改** | 延伸 | 内容符合课标、分量适当、难度适中 |
| **课外辅导** | 辅助 | 个别辅导+集体辅导 |
| **学业成绩的检查与评定** | 检验 | 考试、考查；评分 |

> 📌 教学工作的**中心环节**=上课；备课是**前提**。上课是教师教的活动和学生学的活动**相互作用的最直接表现**。

## 七、教学评价 ⭐高频

### 1. 按功能（作用时间）分类

| 类型 | 时间 | 目的 | 例子 |
|---|---|---|---|
| **诊断性评价** | 教学**前** | 摸底、了解学情 | 入学考试、摸底测验 |
| **形成性评价** | 教学**中** | 改进教学、及时反馈 | 课堂提问、单元测验 |
| **总结性评价** | 教学**后** | 鉴定学习成果 | 期末考试、结业考试 |

### 2. 按评价标准分类

| 类型 | 参照物 | 例子 |
|---|---|---|
| **相对性评价**（常模参照） | 学生群体 | 选拔性考试、高考、排名 |
| **绝对性评价**（目标参照） | 教学目标/课程标准 | 及格率、会考、驾照考试 |
| **个体内差异评价** | 自身过去/不同方面 | 学生前后成绩对比 |

### 高频判断题陷阱

1. ❌"教学就是智育"→教学是实现智育的基本途径，但教学包含德育、体育等；智育也通过其他途径实现
2. ❌"备课就是写教案"→备课包括备教材、备学生、备教法三方面
3. ❌"总结性评价在教学中进行"→总结性评价在**教学后**；形成性在教学中
4. ❌"设计教学法=道尔顿制"→道尔顿制（帕克赫斯特）指定作业自学；设计教学法（克伯屈）学生自己设计
5. ❌"个别教学产生于现代"→个别教学是最**古老**的形式，古代教育基本形式
6. ❌"班级授课制最早产生于中国"→产生于**16世纪西欧**；1862年才传入中国
