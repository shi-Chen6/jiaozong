## 四、处理规则

1. **答案按「题号区间 + 题号」对齐**，不按 token 顺序硬套——PDF 里答案区常被水印和分页切断，顺序套会整段错位。
2. **勘误先于导入**：`09.记忆课件和课后练习题勘误`、`42.勘误` 点名的题目逐条核对后手工修正，再进题库。
3. **完全重复（题干 + 选项都一致）合并**，保留全部来源；同题干不同选项的保留，因为考法不同。
4. **没有可靠答案的题直接丢弃**并留痕，本轮共丢弃 3 题，多为材料分析类（原文答案写「见解析」或缺失）。
5. **材料题 / 简答 / 论述 / 辨析不进单机刷题**：作答方式不同，塞进来会破坏判分与答题交互。
6. **课件习题不重复搬**：授课课件的配套习题与章节练习汇总重合度约 80%%，只补章节汇总里没有的新题。
7. **口诀原文照录**，不为了「对上」而改写；对不上知识点的也留着（例如「直系熟」）。
