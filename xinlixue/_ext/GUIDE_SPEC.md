# 先导知识卡 GUIDE 编写规范（第 4/6/7 章升格用）

本文件是写给撰写者的规范。目标：把课件逐页转录稿整理成刷题网页里的「先导知识卡」数据文件。

## 一、产物

一个 Python 文件 `guide/<章号>.py`，内容只有一个模块级变量 `GUIDE`：

```python
# -*- coding: utf-8 -*-
"""第 4 章 记忆 · 先导知识
来源：07.26记忆上、09.记忆下课件、10.记忆3（逐页转录）
"""

GUIDE = {
    'no': 4,
    'intro': '一段 100~200 字的导语……',
    'secs': [
        {
            'name': '一、记忆概述',
            'map': [ ... ],
            'blocks': [ ... ],
        },
    ],
}
```

- 文件编码声明 `# -*- coding: utf-8 -*-` 必须在第一行。
- 全部用单引号，缩进 4 空格，纯 ASCII 引号（`'`），不要用中文引号做字符串定界。
- 只写数据，不要写 import、不要写函数调用、不要写 `print`。

## 二、字段

### GUIDE

| 键       | 类型   | 说明                               |
| ------- | ---- | -------------------------------- |
| `no`    | int  | 章号，必须与文件号一致                      |
| `intro` | str  | 章导语，100~200 字，说清本章主线 + 课件标了哪几个重点 |
| `secs`  | list | 节的列表，2~5 节                       |

### secs[i]

| 键        | 类型   | 说明                           |
| -------- | ---- | ---------------------------- |
| `name`   | str  | 节名。**必须沿用现有小节的命名**（见任务里给的清单） |
| `map`    | list | 本节知识地图（见下）                   |
| `blocks` | list | 本节正文（见下）                     |

### map 条目

```python
{'lv': 0, 't': '大节名', 'n': ''},
{'lv': 1, 't': '术语', 'n': ''},
```

- `lv: 0` 是分组标题（每个 map 第一条必须是 lv0，内容就是本节名）；
- `lv: 1` 是术语条目，**6~16 条**，取自课件树状图的二级分支名；
- 条目要短（≤14 字最佳），不要写整句话；
- `n` 一般留空字符串；课件明确标了考频时填 `'①'`／`'③'`／`'⑳'` 这种带圈数字。

### blocks 条目（正文，按课件顺序）

只允许这 7 种，键名不能错：

```python
{'k': 'h', 't': '小标题'}                       # 小标题
{'k': 'p', 't': '一段正文'}                      # 普通段落（可含 <b> 标签）
{'k': 'ul', 'items': ['条目一', '条目二']}       # 无序列表（可含 <b> 标签）
{'k': 'table', 'head': ['列1', '列2'], 'rows': [['a', 'b'], ['c', 'd']]}   # 表格
{'k': 'tip', 't': '提示文字'}                    # 灰底提示条
{'k': 'kj', 'c': '口诀原文', 'd': '口诀解释'}     # 记忆口诀（黄色卡片）
{'k': 'img', 'f': 'c24/p012.png', 'cap': '图注', 'alt': '替代文字'}  # 课件原图（base64 内嵌）
```

`img` 块说明：**`f` 写相对 `_ext/gimg/` 的路径**，不要手写 base64。构建时 `build.py` 会自动  
把源图压缩（最长边 1000px、256 色 PNG；超标自动降级 JPEG q78）并转成 `data:image/...;base64,...`  
写进 `src`，交付的 HTML 仍是单文件离线可看。可选 `fmt:'jpg'` 指定照片类用 JPEG。  
`cap` 必写（一句话说清图在讲什么 + 来源页），`alt` 可选。

硬性约束：

- 正文文字字段一律叫 **`t`**。写 `{'k':'p','v':...}` 会直接报错，绝对不要用 `v`。
- `<b>` 用来标课件里的红色/加粗关键词，**每段不超过 3 处**，不要整句加粗。
- `table` 首行是表头；**最多 4 列**，每列 ≤28 字；行数 ≤8 行；超了就拆成两张表或改 `ul`。
- `ul` 每节最多 8 条，单条 ≤60 字；再长就改成 `p`。
- `kj`（记忆口诀）**只在课件里真的给了口诀/顺口溜时使用**，`c` 尽量短（≤12 字），`d` 一句话解释。  
  **绝对不要自己编口诀。** 没口诀的章就不要出现 `kj`。
- 不要出现空块、不要出现 `None`。

## 三、内容要求

1. **以转录稿为准**。术语、人名、理论名、数字（如 7±2、0.25~4 秒、34%）必须与转录稿一致，不许按记忆改写。
2. 转录稿里标了 `【模糊：…】` 的地方，如果上下文能确定标准表述，就按标准表述写；拿不准的**整条略去**，不要猜。
3. 树状图转成「`h` 小标题 + `ul` 条目」或「`table` 对照表」，能做成对照表的优先做表（如 三种记忆对比 / 四种情绪理论对比）。
4. **不要写成题目解析**，这是背诵用的知识卡：一句话给定义、给分类、给关键数字。
5. 相近概念容易混的，用 `tip` 写一句区分（如「短时记忆≠工作记忆，版本一认为相等，版本二认为短时=直接记忆+工作记忆」）。
6. 全章块数控制在 **35~60 块**；每节 8~20 块。宁精不滥。
7. 中文全角标点；`（　）` 这种挖空只在原文是挖空且需要保留时用，否则补全。
8. **图片的取舍（第 24 章起执行）**：先判断这一页是不是「适合直接放」。

   **适合 → 用 `img` 块直接嵌原图**（base64 进 HTML）：
   - 图本身是信息主体，文字无法等价还原：实验装置/示意图（斯金纳箱、波波玩偶、守恒实验）、  
     结构图/思维导图/流程图/时间轴/坐标曲线、有教学含义的漫画情境、人物照片对照。
   - 单页主体就是一张图，图中字大到缩到 430px 宽仍读得清；无「本页来源」弹窗遮挡、无大面积留白。
   - **张数不设上限**（按内容需要，只要属于上面「适合」那一类就嵌）；单图压缩后 ≤80 KB。选定后把页图从 `_ext/p3/kNN/pNNN.png`  
     复制到 `_ext/gimg/c<章号>/`（用 `python _ext/gimg_add.py kNN pNNN c<章号>`），再写 img 块。
   **不适合 → 一律转成表格 / 列表 / 段落**，不嵌图：
   - 纯文字板书、定义、成段论述；文字层可读的教材截图。
   - 知识点能用 ≤4 列对照表或列表无损表达的（优先做表，这是本项目一贯做法）。
   - 模糊、被弹窗遮挡、低对比、重复帧、装饰页/CHAO GE 表情页、整页习题。
   - 图里的信息只是「若干条并列要点」——拆成 `ul`/`table` 比看图更好背。
   拿不准时**默认转表格/列表**，不嵌图。嵌图的唯一理由是「少了这张图信息就丢了」。
