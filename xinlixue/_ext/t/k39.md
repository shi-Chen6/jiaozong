    - 分类标准：新知识与原有认知结构的关系

      - 下位学习
        - 别称 — 类属学习
        - 概念 — 将概括程度较低新知识归属到原有的概括程度高的知识之下【先大后小】
        - 典例 — 先学水果，再学苹果是水果
        - 分类 ㉒
      - 上位学习
        - 别称 — 总括学习
        - 概念 — 新知识具有更高的包容和概括水平【先小后大】
        - 典例 — 先学苹果，再学水果
      - 并列组合学习
        - 别称 — 并列结合学习
        - 概念 — 新学习和原来的知识并列关系
        - 典例 — 质量vs能量、遗传vs变异、热VS体积、需求VS价格、重力场VS电力场
- 下位学习：原有的概念 / 新学习概念（A 下有 a4 a1 a2 a3）
- 上位学习：新学习概念 / 原有的概念 a1→a2→a3→a4（A 在上）
- 并列结合学习：新学习的概念 A--B--C--D / 原有的概念

## p076

**页标题**：认知学习理论

- 二、认知学习理论
- 认知主义的学习理论认为：**学习不是在外部环境的支配下被动地形成 S—R 联结，而是主动地在头脑内部构建认知结构；【反对行为主义】**
- 1. 学习不是通过**练习与强化**形成反应习惯，而是通过**顿悟与理解**获得期待；
- 2. 有机体当前的学习依赖于其**原有的认知结构**和**当前的刺激情境**时，学习受主体的**预期**所引导，而不是受**习惯**所支配。
- 3. 在认知观指导下的学习，被视为一个**知识的自我建构和理解过程**，学习依赖于学生自主的**信息加工系统**，而学习导致**认知结构的变化而非外部行为的变化**。
- 4. 教学目的是**建构知识，获得深层次意义理解**。
