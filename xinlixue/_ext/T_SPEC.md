# 课件逐页转录规范（第 10、11 章）

## 一、任务本质

把课件每一页的**板书内容**抄成 Markdown。这是「抄」，不是「总结」：
- 不要提炼、不要改写、不要补充你自己的知识、不要出题、不要写"这页讲了…"的概括句。
- 课件上的每一行字、每一层括号、每一个数字，都要落到纸上。
- 宁可啰嗦，不可丢信息。后面写先导卡的人只信你的转录稿。

## 二、输出文件

`_ext/t/<课件代号>.md`，每页一节：

```markdown
## p003

**页标题**：能力（P134）

正文……
```

- 页标题写课件上那一行的标题文字（含页码，如 `P134-135`）。
- 页内层级用 Markdown：一级要点用 `- `，二级缩进 `  - `，三级 `    - `。
- 树状图/框架图：按「根 → 分支 → 叶子」转成缩进列表，保留所有叶子节点文字。
- 对照类板书（几种类型、几个理论并列）：转成 Markdown 表格，**原样保留列名和每一格文字**。
- 算式、公式：用行内代码或普通文本照抄（如 `IQ=智龄/实龄×100`），不要美化。
- 强调字：课件里红色/加粗/带☆★的关键词，用 `**词**` 包起来。
- 挖空（原文下划线或空格留白）：写成 `____`，若同一页后面有答案，在页末用一行 `答案：…` 补上。

## 三、读图方法（重要）

1. **一页一图，绝对不要拼图**：图片路径 `_ext/p3/<key>/pNNN.png`，每页 1920×1080，用 Read/ViewImage 单张读。把两张竖着拼成一张再读，识别会整页崩成乱码。
2. 逐页读，读完一页立刻写进 md（不要全部读完再凭记忆写）。
3. **深色底/低对比页读不清**：用 PIL 提亮后再读，例如：
   ```python
   from PIL import Image, ImageEnhance
   im = Image.open('_ext/p3/k20/p009.png')
   im = ImageEnhance.Brightness(im).enhance(1.9)
   im.save('_ext/p3/k20/_b009.png')
   ```
   提亮后仍有 2~3 个字辨不清，写 `【模糊：辨认结果】`，不要空着、不要猜一个看起来合理的词。
4. 纯装饰页（表情包、水印、纯色过渡）在 md 里写 `（装饰页，无内容）` 一行即可，不要编内容。
5. 页面上出现「口诀 / 顺口溜 / 谐音」字样，**必须逐字抄全**，单独一段：

```markdown
**口诀**：猪早想关机抽烟
**对应**：能力分类的八个名称……
```

  只抄课件真有的口诀。没写口诀的页，不要自己编一句。

## 四、常见板书结构怎么转

| 板书形态 | 转法 |
|---|---|
| 中心词 + 若干分支（思维导图） | 缩进列表，根在最外层 |
| 一个概念 + 定义 + 例子 | `**定义**：…` / `**例**：…` |
| 三个理论并列对比 | 表格，列＝理论名/提出者/核心观点 |
| 「① ② ③」编号要点 | 有序列表 `1. 2. 3.`，编号里的字照抄 |
| 优缺点两栏 | 表格，或 `**优点**：…` / `**缺点**：…` 两段 |
| 页脚小字（考频、页码、老师备注） | 页末一行 `> 备注：…` |

## 五、自查（写完每页做一次）

- 这一页课件上有几行字？md 里是不是都有？
- 有没有出现「主要包括」「等等」「等方面」这种**你自己加的概括词**？有就删掉，换成原文。
- 表格的格子数对不对？有没有整列漏掉？
- 有没有把 `【模糊：…】` 当成正常内容略过？
