# 教综刷题

教师招聘「教育综合知识」分章节题库，全部为单文件离线网页，下载后双击即可使用，也可以直接发微信打开。

| 目录 | 内容 | 题量 | 入口 |
| --- | --- | --- | --- |
| [`jiaoyuxue/`](jiaoyuxue/) | 教育学 | 见 `data.js` | `jiaoyuxue/index.html` |
| [`xinlixue/`](xinlixue/) | 心理学 | 2239 题 · 34 章 · 79 节 | [`xinlixue/心理学刷题.html`](xinlixue/心理学刷题.html) |

## 通用特性

- 章节进度、章节重做、答题历史回溯
- 错题本、收藏夹、成绩统计
- 全文搜索（题干 / 解析 / 知识点）
- 每章「考点速览」先导知识卡，关键图表内嵌，完全离线
- 移动端 430px 版式，桌面端居中显示

答题记录保存在浏览器 localStorage，换设备不互通。

## 说明

题目与解析整理自公开课件的授课内容，仅供个人学习备考使用，请勿用于商业用途。各目录内的 `README.md` / `资料归并说明.md` 记录了归并口径、校验结果与已知缺口。
